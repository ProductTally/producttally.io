คำตอบสั้น ๆ

ในการทดสอบบนเว็บ บัญชีฟรีสร้างและแก้คำบรรยายอัตโนมัติได้ แต่การดาวน์โหลดวิดีโอพร้อมคำบรรยายต้องใช้ Pro

รีวิว CapCut

นำเข้าคลิป

สร้างโปรเจกต์ เลือก Upload → Upload file แล้วลากคลิปที่มีเสียงพูดชัดไปบนไทม์ไลน์ กดเล่นเพื่อตรวจเสียง

สร้างแทร็กคำบรรยายแรก

ไปที่ Captions → Auto captions เลือกภาษาที่พูดแล้วกด Generate จะเห็นบล็อกคำบรรยายเหนือวิดีโอ

แก้คำและจังหวะ

เลือกบล็อกแล้วตรวจชื่อ ตัวเลข และเวลา เปิดคลิปตั้งแต่ต้นเพื่อตรวจจังหวะ สำหรับคลิปแนวตั้งให้เผื่อพื้นที่ด้านล่าง

เปิด Captions → Auto captions เลือกภาษาที่พูด แล้วกด Generate วันที่ 11 พฤศจิกายน 2026 บัญชีเว็บใหม่ที่ไม่ได้สมัครแพ็กเกจสร้างคำบรรยายภาษาอังกฤษแบบสหรัฐฯ ได้สี่ช่วงจากเสียงสังเคราะห์เก้าวินาที เราแก้ “product tally” เป็น “ProductTally” แล้วตรวจว่าการแก้ไขยังอยู่หลังเปิดและอัปเดตโปรเจกต์อีกครั้ง ควรตรวจชื่อ เวลา และจังหวะการแบ่งบรรทัด

ตรวจการดาวน์โหลดตั้งแต่ต้น

เปิด Export → Download หากเข้าหน้าตั้งค่าได้ ให้ดาวน์โหลดคลิปสั้นเพื่อดูว่าคำบรรยายอ่านง่ายและตรงจังหวะหรือไม่ หาก Auto captions ขึ้นว่าเป็น Pro ให้ลองทางเลือกถัดไป

ลองพิมพ์เองหรือนำเข้า SRT

ใช้โปรเจกต์สั้นแยกต่างหาก เลือก Manual captions หรือใช้ Upload caption file กับไฟล์ .srt แบบ UTF-8 เมื่อเห็นบล็อกที่แก้ไขได้ ให้ลองดาวน์โหลดอีกครั้ง ผลดาวน์โหลดของทางเลือกเหล่านี้ยังไม่ได้รับการยืนยัน
