Printify 第一件 T 恤样衣怎么验收？

下单前选定计划销售的款式，收到样衣后核对印花尺寸、位置、细节和面料。

作者 Evan · 更新于 2026年11月17日

用准备上架的配置在 Printify 下样衣单。把印厂、衣款、颜色、尺码和图稿记在同一份记录里。等实物到手，按订单配置逐项验收，再决定是否使用这件样衣拍摄和上架。

Printify · 查看产品详情

先在 Printify 下样衣单

进入 My Products 或 Orders，选择 Create order → Sample。添加准备销售的商品，检查配送地址。Printify 说明样品按常规价格结算，Premium 会员可以享受适用的基础价优惠。样衣没有额外专属折扣。若要验证个性化商品的买家体验，官方建议从销售渠道下测试单。

出处为 Printify 帮助中心《How does sample ordering work?》

  • Printify 运费表

收到样衣后，按实际尺寸检查

测试 PNG 可以加编号、小字和细线。提交前记下印花宽度。收货后量印花两端的距离，在正常光线下看小字是否清楚，并拍下衣服和印花位置。把照片与订单配置放在一起，方便复查。

如果后来换了印厂、面料或印刷方式，重新打样再确认。这里提供的是一套建议的收货验收流程。
