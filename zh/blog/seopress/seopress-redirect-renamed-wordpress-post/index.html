WordPress 文章改地址后，怎么用 SEOPress 做一条 301？

把旧文章地址直接转到新页面，再从访客视角检查实际跳转路径。

作者 Evan · 更新于 2026年11月20日

同一篇文章永久换地址时，可以建立直接的 301 重定向。假设原来是 /blog/old-workshop/，现在改为 /blog/workshop-checklist/。迁移记录写下新旧完整地址、负责人和生效时间。

SEOPress · 查看产品详情

给旧地址建一条直接规则

SEOPress 把重定向管理列为 PRO 功能。到 SEO → Redirections 建规则，Origin URL 填旧相对路径，目标填完整的新网址。选择 301 并启用，然后使用 Test URL。旧链接如果已经发到带参数的广告或邮件里，再决定是否保留查询参数，按选择的匹配方式验证。

  • Setting up redirections
  • SEOPress PRO redirect manager

从访客视角走完跳转

用退出登录的访客窗口打开旧链接，确认它直接跳到新页面，目标返回 200。把导航、可修改的站内链接和地图更新为新规范地址。再把新链接发给团队，日后分享走新地址，老书签也能经 301 找到内容。
