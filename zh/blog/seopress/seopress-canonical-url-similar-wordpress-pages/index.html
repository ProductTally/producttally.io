WordPress 有三个相似产品页，SEOPress 该把哪个设为主页面？

用常规页、活动副本和独立地区页演示 canonical，检查最终源代码和 Google 选择的主 URL。

作者 Evan · 更新于 2026年11月18日

先判断这页是否是同一内容的副本，或者确实需要满足另一地区的购买需求。假设正常产品页是 /studio-desk/。广告活动额外做了一个只换标题、其他内容相同的副本，地区版则有当地币种、配送与退货条件。让活动副本指向常规页；确实有独立内容和市场用途的地区版，可保留自己的 canonical，再按需要配置 hreflang。Google 把 canonical 当作选择代表网址的信号，仍可能选择不同 URL。

常规产品页指向自身常规搜索和站内入口

有独立当地政策的地区页指向自身当地币种、交付条件和退货说明

保存回前台，再查浏览器拿到的信号

在活动副本的 SEOPress SEO metabox 打开 Advanced → Canonical URL，填入常规页的绝对 URL。保存后清掉适用缓存，打开前台页面源代码确认 <head> 中只有一个有效的 rel="canonical"，而且目标能返回预期页面。分别核对常规页与地区页的输出，检查站内链接和 XML sitemap 有没有仍把活动副本作为主入口。

  • SEOPress 自定义 canonical

如果地区页确实要分别出现在搜索结果里，检查每版的 hreflang 是否包含自己的完整 URL 和其他地区版本，并且各版互相引用。同语言地区页的主要内容高度相同时，先按 Google 指南评估是否应选择首选规范页。

如果活动页的确要从搜索结果排除，单独评估可抓取页面上的 noindex。把 URL 写进 robots.txt 会限制抓取，也可能使 Google 看不到页面中的 canonical 或 noindex。若页面本来就包含仅面向内部的内容，使用真实访问控制。最后在 Search Console 分开看自己声明的 canonical 和 Google 已选择的版本。
