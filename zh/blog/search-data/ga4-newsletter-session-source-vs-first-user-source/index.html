邮件带回了老访客，GA4 应该看会话来源还是首次用户来源？

用同一位读者的两次访问，找到衡量邮件活动时正确的 GA4 报表。

作者 Evan · 发布于 2026年11月28日 · 更新于 2026年11月28日

看邮件带来的访问，要打开「流量获取」并使用「会话来源/媒介」。看访客最初怎样发现网站，则打开「用户获取」，使用「首次用户来源/媒介」。同一个人在两张表里的来源可以不同。

两张获客报表 · 流量来源的统计范围

周一从搜索来，周五从邮件回来

假设一位读者周一从自然搜索找到模板商店，周五点邮件里的链接回来。邮件网址使用 utm_source=maker_weekly 和 utm_medium=email。假设 GA4 识别出同一用户并记录了两次独立会话，首次用户来源仍是自然搜索，周五这次会话可归到邮件。

  • 两张获客报表
  • 流量来源的统计范围

怎么看这次群发带来的访问

在「流量获取」里选活动日期，查看「会话来源/媒介」中的 maker_weekly / email。如果同一个发件方做了多次活动，再按「会话广告系列」拆开。先以会话数为口径，比较两封邮件时沿用相同的维度与时间窗口。新访客最初从哪里来，可以另查「用户获取」。

  • 两张获客报表
  • 流量来源的统计范围

给报表写上准确的指标名

周报中把数字标为「归因到 maker_weekly / email 的会话数」。若要进一步回答购买应该归功于哪个渠道，要另外核对关键事件和归因模型。会话来源与关键事件归因是两个统计口径。
