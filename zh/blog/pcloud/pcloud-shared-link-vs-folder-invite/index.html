发客户文件时，谁应该拿到 pCloud 链接，谁要加入文件夹？

对照审阅、协作和归档三个场景，在 pCloud 检查访客访问、编辑权限和撤销方式。

作者 Evan · 更新于 2026年11月18日

客户只需看一份方案或自行下载时，先用 Shared Link，并按当前套餐设置有效期等访问条件。需要持续加文件、替换输出稿，或给同事明确的编辑权限时，再用 Invite to folder。共享链接可以交给没有 pCloud 账户的收件人；邀请文件夹用于同 pCloud 用户协作。

你要交付什么

  • pCloud 共享链接
  • pCloud 邀请进文件夹
可以怎么开权限
你要交付什么可以怎么开权限用访客身份看什么
客户只审阅方案分享单个文件，按可用设置加密码或有效期确认能打开这份方案，进入不了项目其他文件
两位同事轮流交接邀请到专门的交付文件夹，按需给 Edit核对能添加和替换文件，确认谁能转发邀请
客户留存一套成品从独立的归档目录给 View 或按需发归档链接下载包只含已确认的版本，且访问能按约定结束

Edit 和 Manage 的差别在谁可以再分享

pCloud 官方把 View、Edit 和 Manage 分开。Edit 可以添加、修改和删除；Manage 还能把访问分享给其他人。文件夹设置的权限也会作用到下属文件和目录。一个目录里既有外发文件又有内部草稿时，另建只含外发内容的目录再授予访问。结束试运行后，在管理入口撤销一个测试成员及一条测试链接，再分别检查旧入口会显示什么。

  • pCloud 邀请进文件夹

按 pCloud 说明，文件夹邀请要求双方账号位于同一数据区，也就是同在欧盟区或同在美国区。共享链接可供没有账号的访客在浏览器预览。共享链接密码和自定义到期时间属于 Premium 功能，发送前先核对这些条件。

如果协作者的账号分属不同数据区，pCloud 文档提供了一个收文件的做法，给共享链接开启上传，让对方用 pCloud 账号上传。如果只需要收文件，也可以评估文件请求。上传者无需看到文件夹里原有的内容。
