用 HelpCrunch 发布西语帮助中心，应该先翻译文章还是分类？

把一条西语帮助路径完整发布，让读者从语言入口一路找到答案。

作者 Evan · 发布于 2026年11月28日 · 更新于 2026年11月28日

HelpCrunch 的译文挂在主语言文章下面。先发布主语言原文，再在翻译语言设置中加入西语。保存并发布西语文章前，先补齐文章所在的分类和栏目。

多语言帮助中心设置

HelpCrunch · 查看产品详情

选一篇客户现在就能找到的文章

例如先做「如何更改账单邮箱」。确认主语言文章已经写清操作入口，并与产品给用户显示的名称一致。进入 Knowledge Base → Settings → Languages for translation，添加西语并填写西语帮助中心名称。

  • 多语言帮助中心设置

把读者通往答案的路径一起翻译

回到主语言文章，在编辑器里切换到西语。除了正文，也翻译分类和栏目，让读者从西语首页就能找到这条说明。HelpCrunch 会在你保存文章翻译前提示缺少的分类或栏目译文。顺手核对截图说明和文内链接，看看它们在西语版里是否可用。

  • 多语言帮助中心设置

从公开页面走一遍

打开帮助中心，用公开语言选择器切到西语，从分类找到文章。其他缺漏可以查看 Translation Report。若西语译文需要持续可见，要保留主语言文章启用，因为停用主文章会自动停用所有译文。
