站点地图显示「成功」，为什么还有页面搜不到？

对照站点地图上次读取时间、已发现网页数，以及单条网址的索引状态。

作者 Evan · 更新于 2026年11月19日

Search Console 的站点地图「成功」指地图已被读取和处理。「已发现的网页」数的是从地图里解析出的地址。要查某篇文章有没有收录，用网址检查打开它的规范地址，查看已索引版本。

把三个日期对在一起

发布后，记下部署时间、站点地图提交时间和「上次读取」时间。打开公开 XML，找一个刚上线的规范地址。文件里有它、上次读取又早于部署，说明控制台看到的地图落后于当前版本。保留现有地图地址，等 Google 读取后再看报告。

  • Search Console 站点地图报告

拿一篇没搜到的文章走完两层报告

假设你新发了一篇西语文章，它的地址已在 XML 里。先在「网页索引」里用地图筛选查看这批页面，再用网址检查打开那条准确地址。看索引状态、最近抓取和 Google 选择的规范地址。如果规范地址指向别处，核对两个版本，并检查站内链接和地图是否都指向你准备发布的主版本。修完后可跑实时测试看当前页面是否具备索引条件。

  • Search Console 站点地图报告
  • 网址检查与排查

发布记录分两行写

第一行记哪些新地址已经进入地图，第二行记抽查过的地址是否已收录。实时测试针对当前线上版本，已索引视图反映 Google 现有记录。把两个状态保留下来，下次复核就知道该追哪一层。
