上线后用 Bing IndexNow，应该提交哪些地址？

根据发布差异选出需要通知的地址，并核对 Bing 的接收状态。

作者 Evan · 更新于 2026年11月19日

IndexNow 用来通知参与的搜索引擎：某个准确的网址新增、变更或移除了。站点地图可以继续提供规范网址供日常发现。等线上页面达到预期状态再通知，并记下服务返回的结果。

从本轮真正变化的地址整理批次

假设本轮新增一篇指南、更新一个价格页，同时撤下一则公告。把新指南和价格页加入通知。先检查旧公告地址：有合适的新页时设重定向，内容确实移除时确认返回合适的 404 或 410。通知时也带上这条已发生变化的旧地址。使用同一已验证主机下的完整网址。

  • IndexNow 协议
  • Bing IndexNow 接入说明

看到 200 或 202，下一步不同

Bing 的接入说明使用密钥文件验证站点。协议里的 200 表示通知提交成功，202 表示已收到网址，仍在等待密钥验证。主机或密钥不匹配可能返回 422，429 表示请求过多。先记录响应并处理问题，再决定是否重试。

  • IndexNow 协议
  • Bing IndexNow 接入说明

接收结果写进发布记录

记下变动地址、实际 HTTP 状态和 IndexNow 的响应。从 XML 地图里去掉已经撤下的规范地址。Bing 可以通过地图发现变化，也可以从网址本身读到新的响应。如果要知道新地址有没有进入 Bing 索引，用网址检查另查。
