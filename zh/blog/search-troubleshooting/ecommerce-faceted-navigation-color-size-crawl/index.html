商品颜色和尺寸筛选 URL，哪些适合给 Google 抓取？

用一个鞋类目录区分有独立需求的落地页和购物时临时使用的筛选链接。

作者 Evan · 发布于 2026年11月27日 · 更新于 2026年11月27日

网店会为颜色、尺码和排序产生很多 URL，先决定哪些页面有独立价值。Google 说明，不希望被收录的筛选模式可以限制抓取；若要让选定的筛选落地页参与搜索，则保持 URL 规范，并给商品留出可访问的导航链接。

官方文档 · developers.google.com 1 · 官方文档 · developers.google.com 2

用一个类目做取舍

鞋店可以保留 /shoes/ 作为主目录。如果红色跑鞋长期有货，也能提供有用的购买信息，就可以给它维护独立页面。临时切换成 42 码再按价格排序，通常是购物界面的状态。希望被发现的商品仍需要从可抓取类目或商品链接进入。

查空结果和重复组合

允许抓取筛选页时，Google 建议过滤顺序一致、使用标准参数分隔符，没有结果的组合返回 HTTP 404。要限制抓取时，先检查规则是否误伤商品和类目。已经索引的网址是否需要移除，要单独处理。
