Teachable 主讲、助教和运营怎么分权？

用访问矩阵核对课程编辑、学员进度和财务权限，并在不同账号中实际检查。

作者 Evan · 更新于 2026年11月17日

先列出每个人实际要做什么，再在 Teachable 的 Settings → Roles 查角色权限。默认角色适合常规分工；权限需要更细时，再核对你的套餐是否提供自定义角色。给助教开教学反馈权限前，应先确认会不会同时看到不相关课程或支付信息。

按职责核对访问权限

岗位权限的验收示例
成员要完成的工作需要另外验证的地方
主讲修改指定课程的内容、发布前核对讲义其他课程和财务是否可见。
助教看职责范围内的学员进度，在批准的渠道给反馈能否编辑课程、导出名单或进入别的班。
运营处理报名、账号和必要的结账事务退款与收入可否进一步限制，是否需要额外管理员名额。

较新的《Types of User Roles》把自定义角色列为 Growth 及以上可用，而《Custom User Roles》仍写 Business。查看当前套餐，并确认学校账号的 Settings → Roles 里是否有相应控件。表里的三种岗位是要验证的权限目标。

出处为 Teachable 帮助中心《Types of User Roles》《Admins》和《Custom User Roles》

用独立测试账号验证每个角色

给每种角色安排一个测试账号，不共用主账号。打开各自需要访问的页面，再尝试打开不应该进入的课程或财务页。发现助教只有通过更高权限才能完成某项工作时，先拆分操作职责，把该部分交给现有负责人。把测试日期、角色名和实际结果记录下来。人员变更之后，用同一张表复查剩余权限。
