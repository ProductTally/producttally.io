n8n 固定数据怎么用？编辑器里的样例和生产运行的区别

用一条虚构表单开发下游节点，并确认正式运行会从哪里取数据。

作者 Evan · 更新于 2026年11月23日

在 n8n 里固定节点输出，编辑器运行时就能重复使用同一条数据。生产执行会忽略固定数据，读取当前输入。开发表单分流时，同事可以共用一条虚构记录，无需复制真实客户资料。

n8n · 查看产品详情

选一条能讲清楚流程的样例

假设工作室的咨询表单会提交项目类型、语言和计划日期，后面的节点负责分配队列。可以做一条 projectType 为 newsletter、language 为 es、日期为虚构值的输入，方便说明为什么这条需求会进入西语通讯队列。

按 n8n 文档固定支持此操作的节点输出。之后在编辑器执行下游节点，就可以沿用这一条输入。改分流规则或通知文案时，不用为每次修改都重新提交表单。

  • n8n 帮助 · 用有代表性的节点输出编辑工作流

先分清是在改路由，还是查表单

如果是在改分流，一条已知的输入很好用。如果要确认表单是不是改了字段名，就取消固定，再取一次新输入。保留旧样例会让你继续看到旧字段，无法判断当前提交长什么样。

交接时写清钉在哪个节点、样例特意包含哪些字段，以及还需要考虑哪种输入，例如漏填语言。共享工作流里的样例避免放凭据、联系方式和客户备注。

  • n8n 文档 · 模拟和固定数据
  • n8n 帮助 · 用有代表性的节点输出编辑工作流

上线后真实提交会走哪一条？

启用的工作流收到表单提交后，生产运行会读取这次真实事件的数据。固定的数据给编辑器使用。发布修改之前，尤其是下游要发通知或写入共享系统时，确认正式运行会进入哪个队列或目标。
