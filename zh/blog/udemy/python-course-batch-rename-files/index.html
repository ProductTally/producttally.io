Udemy Python 入门课怎么选？先做一个批量重命名项目

用客户照片交付场景核对课程是否讲文件路径、循环和同名冲突处理。

作者 Evan · 更新于 2026年11月23日

在 Udemy 选 Python 自动化入门课，先看文件路径、循环和错误处理，再用一个复制的文件夹练习。改动前列出原文件名和目标文件名，遇到重复目标或同名文件就先处理冲突。

Udemy · 查看产品详情

把交付文件夹变成你要学的任务

假设摄影师要交付客户相册。三张照片叫 DSC_0041.jpg、DSC_0042.jpg 和 DSC_0043.jpg，客户希望统一成 studio-001.jpg 这样的名字。适合这份任务的课程，应当讲怎样从一个目录选出文件、读到名称，再按确定的顺序逐个处理。先想清楚顺序是按名称，还是要与拍摄清单一致。

Al Sweigart 的 Udemy 课程《Automate the Boring Stuff with Python Programming》公开大纲列出了流程控制和错误处理。作者另有一本书，其中的文件整理章节有一个改名项目。可以先看书里的示例了解文件操作，再决定要不要学课程。这里的相册练习是另写的。

  • Al Sweigart 的 Udemy 公开课程大纲
  • Al Sweigart 的书 · 文件整理章节

先写出一份你能读懂的改名清单

复制整个文件夹，再放一份 notes.txt。只给 JPEG 规划新文件名，逐行打印原名称与目标名称。比如 DSC_0041.jpg 对应 studio-001.jpg，保留 .jpg 后缀，不处理备注文件。一个交付目录里混着不同相机或批次的照片时，先看预览能避免顺序跑偏。

然后在练习文件夹预放一张 studio-002.jpg，看清单会不会标记冲突。所有目标都唯一之后，再对副本应用规则，把改名对应表留给交付的人。用这个练习回看课程大纲，你就知道自己需要的是能看懂并控制一次批处理的教学。
