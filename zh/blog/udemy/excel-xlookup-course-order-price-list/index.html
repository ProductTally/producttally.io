Udemy Excel 课怎么选？用 XLOOKUP 核对订单和价目表

用一个 SKU 对账练习，检查课程是否讲精确匹配、缺失值和重复编码。

作者 Evan · 更新于 2026年11月23日

在 Udemy 选 XLOOKUP 课程，先看大纲是否覆盖精确匹配、找不到值和搜索顺序。用订单 SKU 去价目表找单价，再分别处理缺失和重复编码，才算做完一次对账。

Udemy · 查看产品详情

用一张能验算的订单挑课

假设摄影工作室卖定制印刷品。价目表里 A01 是 18 美元，B02 是 24 美元。导出的订单有两件 A01 和一件 C03。按 SKU 查价后，A01 这一行应为 36 美元，C03 则显示待核价。暂时把那一行留给负责人确认，避免把空值当零元。

价目表编码在 F2:F4、金额在 G2:G4 时，可以在练习里用 =XLOOKUP(A2,$F$2:$F$4,$G$2:$G$4,"缺少 SKU")。函数名称和分隔符以本地 Excel 为准。先确认查到的价格来自编码完全相符的那一行。

同一编码有两行时，先处理哪条价格有效

在价目表里再加一条价格不同的 A01。XLOOKUP 默认从第一项向后搜索。一条结果未必代表有效价格。把重复编码标出来，再按生效日期或向定价负责人确认，避免发出未经核实的账单。

Udemy 链接里的公开课程大纲列了 match mode 和 search mode。若有试听，先看它如何讲这两个参数。也检查工作电脑上的 Excel 版本是否支持 XLOOKUP。没有异常行练习时，可以直接用上面的缺码与重码场景补上。
