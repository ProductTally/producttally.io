用 DeepL Translator 翻定价页，怎么统一产品名和每席价格？

做一份英语到日语的术语表，用同一段定价页面核对品牌名、按钮、美元与计费周期。

作者 Evan · 更新于 2026年11月18日

先把全站要统一的短词交给 DeepL glossary，再把数字、币种和整个按钮句子当成页面内容另行校对。比如，英文的 annual billing 与 per seat per month 必须同时保留，才能让读者知道「按月计算、按年结算」。术语表能指定词或短语的译法，实际价格和购买条件仍应以定价源数据为准。

把整块页面跑一遍，再看结账

先用上表建立相应语言对的术语表。自动翻完后，打开上下文里的标题、费用行和窄屏按钮。比如输入「Studio Desk · View plans · US$12 per seat per month, billed annually」，可以把「Studio Desk／プランを見る／1シートあたり月額12米ドル（年払い）」作为团队验收文本。这是手工定义的目标稿。当前账号是否支持该语言对和使用路径，要在实际使用的 Translator、文档或 API 中核对。

  • DeepL 创建术语表

在网页版手动建术语表时，打开 Glossaries，选择新建并指定语言对。每个源术语先填一个批准译法，再拿实际价格行试译并检查最终页面，确认后再批量使用。

随后用两席位检查一次价格。在无折扣、税费另计的示例下，12 美元乘 2 席再乘 12 个月应是 288 美元的年度基础费用。日文译文若漏写年付，或者把「每席位」放错位置，读者就可能误会。页面里有自动替换变量时，单独核对变量有没有原样保留，渲染后再看实际价格和按钮。把最终面向用户的字符串存进各语言的价格页内容，之后换币种或方案时可以重新跑对应的用例。
