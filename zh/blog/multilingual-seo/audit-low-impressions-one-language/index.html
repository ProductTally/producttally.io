四语网站有一版长期没流量，怎么查 hreflang 和翻译入口？

用 ProductTally 的四语文章做公开 HTML 核对，依次检查返回状态、canonical、双向语言链接和搜索查询。

作者 Evan · 更新于 2026年11月17日

先选同一篇文章的四个真实地址。检查每个页面能否正常打开、指向哪个规范地址，以及四个语言版本是否彼此声明。页面正常之后，再去看该语言页面实际获得了哪些展示。这样做能区分发布故障和搜索表现问题。Google 的文档说明，语言标注帮助搜索系统把适合的版本提供给用户。

从四个 URL 开始，先看 HTML

以 ProductTally 的 Cal.com 预约缓冲为例。我在 2026 年 11 月 17 日读取了英文根路径和中文、日文、西班牙文路径的公开 HTML。四个页面都成功返回，canonical 分别指向各自 URL，语言版本每页都包含 en、zh-CN、ja、es 与 x-default，共指向四个不同页面。

你也可以用一个小表记录「当前 URL、最终返回 URL、canonical、语言链接」。点击每条语言链接，检查目标页是否也声明回链和自身；页面源代码的语言链接应使用完整地址。中间如果查出某一语言被重定向到英文、返回 404 或错误指向英文 canonical，就先修对应 URL，再看内容表现。

用落地页找查询，别先按站点总流量判定

在 Search Console 中选对应语言页面的 URL 与同一统计时段，检查展示和有数据的查询。日文版的问题可能不是不会被发现，而是标题用了直译的术语，与读者在当地市场真正搜索的表达不同。拿显示的查询与读者具体要做的任务逐个对照，再决定标题是否要改。数据少时可以延长观察期，避免把一天的零展示当作规律。

互链检查确认的是这四个页面的技术设置。抓取、索引和实际搜索曝光分别从对应报告核对。保留表格和检查日期，下次改标题或调整语言 URL 时，按同样四个地址重做一遍。
