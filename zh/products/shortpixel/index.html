产品功能

  • WordPress 插件支持批量优化现有媒体库图片，也可处理新上传的图片。
  • 可选无损、Glossy 或有损压缩，生成 WebP、AVIF 版本；支持优化 JPEG、PNG、GIF 和 PDF。
  • 免费额度为每月 100 个优化积分。缩略图也消耗积分，因此上传一张图片可能需要多个积分。

为什么选择它

  • 在 WordPress 内批量处理已有媒体库，省去逐张导出文件的操作。
  • 优先保留画质时可选无损模式，也可比较 Glossy、有损模式下的体积与画质。
  • 集中处理历史图片可选不过期的一次性积分，持续处理图片则可比较订阅套餐。

如何开始使用

  1. 在 WordPress 安装并启用 ShortPixel Image Optimizer，在插件设置中填写自己的 ShortPixel API Key 并验证。
  2. 选择压缩模式和原图备份设置，先处理少量照片与图文素材，检查画面效果。
  3. 通过“媒体 > Bulk ShortPixel”处理其余图片。估算积分时计入缩略图，优化后清理网站缓存。

批量处理前，先在插件中核对图片范围、压缩模式、备份是否保留及预计积分用量。
