适合谁用

n8n 适合需要逐步核对输出的重复流程。比如先手动运行一批草稿和待发布记录，确认筛选规则只放行正确稿件，再接入发布工具。

如何开始使用

  1. 下载 JSON，在 n8n 的工作流菜单中选择「从文件导入」。打开后手动执行。样例由手动触发器和两个 Code 节点组成，使用虚构记录，无需连接外部账号。
  2. 第一个 Code 节点创建三条记录，每条包含 lang、title 和 status。第二个节点只保留 status 严格等于 ready 的记录，再用 lang 生成示例路径。打开输出，应看到 en 和 zh-CN，西语草稿不在其中。
  3. 把西语样例的状态从 draft 改为 ready，然后重新运行。预期输出三条。生成的路径是示例字符串。接入自己的网站时，请明确配置各语言对应的真实路径，核对输出后再连接后续步骤。

先用一条草稿和两条待发布记录运行。把草稿改为待发布后再运行一次，确认三条都进入队列。
