产品功能

  • FastPixel 集成页面缓存、HTML/CSS/JavaScript 压缩、关键 CSS 和 CDN 分发。
  • 图片优化使用 ShortPixel 技术，支持自适应尺寸、懒加载和自动 WebP 分发。
  • 页面与 JavaScript 排除设置可让指定页面或脚本保持不优化。
  • Free Plan 覆盖 1 个网站、每月最多 1,000 次页面浏览；付费套餐提高浏览量和网站数量额度。

为什么选择它

  • 在一个 WordPress 插件中管理缓存和前端资源优化。
  • 通过 CDN 分发优化后的图片，省去逐张导出处理。
  • 需要保留原有行为的页面或脚本，可以单独设置排除。

如何开始使用

  1. 在 WordPress 的插件页面搜索 FastPixel Website Accelerator，安装并启用，按提示连接账户。
  2. 打开 FastPixel 设置，核对页面、图片及 JavaScript 选项；需要保持原样的页面或脚本可加入排除项。
  3. 检查缓存状态；对显示 Stale 的页面使用 Cache Now，查看缓存后的页面，并在资源完成缓存后进行速度检查。
