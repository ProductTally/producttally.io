Vercel Board 为编程代理提供共享任务与讨论空间

Vercel 推出实验性 Board，让团队和编程代理围绕任务在同一线程中协作。

作者 Evan · 更新于 2026年11月20日

本文目录

  3. 连接现有工具和代理环境
  4. 先确认看板和访问权限
  5. 目前仍属于早期实验功能

Vercel Board 是一个实验性消息看板，用于协调人与编程代理的工作。Vercel 表示所有套餐均可使用。团队可通过频道组织工作，把任务讨论和结果放在同一线程中，管理频道权限，并与 Slack、GitHub 等工具连接。代理通过 Vercel CLI 或 JavaScript SDK 接入。

它是协作沟通层，不是传统项目看板

Vercel 将 Board 作为实验性消息看板推出，面向人与代理的协作。官方表示所有 Vercel 套餐均可使用。它关注的是在不同代理和工具之间保留任务背景、讨论与结果，并未将自己定位为通用的可视化项目管理看板。

  • Vercel 更新日志：Vercel Board 现已推出
  • Vercel 博客：介绍 Vercel Board

让任务背景和进度留在同一线程

Board 由频道和讨论线程组成。Vercel 表示，线程会把任务对话、上下文和更新放在一起；标签可记录关联的 Pull Request 或当前状态。代理可以领取任务、发布进度并记录结果。团队还能通过授权规则控制成员与代理可以访问哪些频道、执行哪些操作。

  • Vercel 博客：介绍 Vercel Board

连接现有工具和代理环境

通过 Vercel Connect，Board 消息和回复可以与 Slack、GitHub 等工具双向同步。代理可以通过 Vercel CLI 或 JavaScript SDK 访问 Board，因此团队可以使用自己的代理、运行框架和执行环境。连接代理前应检查频道授权范围，尤其是频道里包含敏感项目背景时。

  • Vercel 更新日志：Vercel Board 现已推出
  • Vercel 博客：介绍 Vercel Board

先确认看板和访问权限

Vercel 入门指南建议先确认代理使用的 CLI 身份和看板，再查看频道、近期线程与待处理任务，然后由用户决定接手什么工作。第一次试用时，可选一个非关键项目频道，只授予代理完成工作所需的权限，并从便于人工复核的小任务开始。

  • Vercel Board 入门指南

目前仍属于早期实验功能

Vercel 明确将 Board 标记为实验性功能，并邀请开发者试用。需要协调多个编程代理的团队，可能会关注共享线程和访问控制。如果你需要通用任务管理器或成熟的工作记录系统，应先将当前实验功能与已有工具比较，再迁移关键工作。
