Dropbox 宣布 DBX Agent Cloud：Tigris 对象存储面向谁？

作者 Evan · 发布于 2026年11月19日 · 更新于 2026年11月24日

厂商公告 2026年11月5日

Dropbox 于 2026 年 11 月 5 日公布两项更新。AI 文件工作区面向已有 Dropbox 文件的团队，可以搜索和处理现有文件。DBX Agent Cloud 面向开发 AI 应用的团队，从 S3 兼容对象存储起步。11 月 17 日，Dropbox 确认已完成对托管对象存储服务商 Tigris 的收购。

同一家公司，面向两类工作的产品

新的 Dropbox 体验把 AI 搜索和文件操作加入熟悉的文件存储与协作工作区。DBX Agent Cloud 则是面向基础设施的另一条路线：Dropbox 表示它将从可独立购买的对象存储开始，供企业搭配自己选择的云和计算平台使用。收购 Tigris 对应的是开发者产品方向，并不意味着日常使用的 Dropbox 文件夹改变了用途。

  • Dropbox 下一阶段与 DBX Agent Cloud（11 月 5 日发布，11 月 17 日更新）

团队能在新的 Dropbox 体验里做什么

Dropbox 表示，用户可以询问文件内容、总结文件夹、比较版本、起草文档、编辑 PDF 和图片、转写录音，以及整理或重命名文件。执行支持的更改前，Dropbox 会先展示待批准的计划；操作遵循现有权限，并可查看记录或撤销。

适用范围需要留意：截至 Dropbox 11 月 17 日的更新，首批面向美国、英国和澳大利亚符合条件的 Standard 与 Advanced 团队，最初提供英语体验。Dropbox 称已有超过 7 万个团队获得该功能，并计划在 2027 年扩大覆盖。其管理员指南说明 AI 体验包含在 Standard 和 Advanced 套餐内，但聊天请求和 AI 操作会使用团队 AI 额度。安排多人工作流前，先确认团队是否已开通以及剩余额度。

Tigris 对开发者有什么用

Tigris 将自己的产品定位为 S3 兼容对象存储，面向运行在不同云和计算平台上的应用。开发者可使用熟悉的 AWS SDK，以及 AWS CLI、boto3 等工具接入。Dropbox 表示 DBX Agent Cloud 初期提供可独立购买的对象存储；文件系统和内容处理能力属于计划中的后续方向，当前不要把它们当成已经上线的功能。

当团队正在开发 AI 应用或智能体，需要持久保存文件、数据集或生成媒体时，Tigris 才更相关。它是托管云服务，但产品类别更接近开发者基础设施存储，而不是面向创作者的通用项目协作 SaaS。

小团队该评估哪一条产品线？

如果团队的文件已经放在 Dropbox，先检查新体验是否对团队开放、适用哪个套餐，以及 AI 额度如何共享。可以从低风险文件夹开始试用，并在批准前核对 AI 提议的操作。

如果你在开发 AI 应用，则应按存储需求评估 Tigris 或 DBX Agent Cloud：S3 API 兼容性、计算运行位置、访问控制、当前价格，以及现阶段实际可用的功能。不要只根据路线图做决定。简单区分：Dropbox 工作区帮助人们处理文件；Tigris 提供开发者可以集成进软件的对象存储。
