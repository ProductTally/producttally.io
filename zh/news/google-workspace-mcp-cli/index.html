Google Workspace MCP 正式开放，团队怎么接入？

作者 Evan · 发布于 2026年11月26日 · 更新于 2026年11月26日

厂商公告 2026年11月24日

2026 年 11 月 24 日，Google 宣布 Google Workspace MCP 服务器和官方 CLI 正式开放，面向 Workspace 客户和开发者分批推送，预计两周内完成。MCP 用于让支持该协议的 AI 工具按授权访问 Gmail、Drive 等应用。团队可从一次只读的项目周报开始，先确认助手、授权范围和管理员策略。

Google Workspace 公告：MCP、CLI 与管理控制

什么时候用 MCP，什么时候用 Workspace CLI？

网页或云端 AI 助手可接入 Google 托管的远程 MCP 服务器。此次公告涵盖 Gmail、Drive、Docs、Sheets、Slides、Calendar、Chat 和 Tasks。主要在终端工作的团队可看 Google Workspace CLI（gwscli），通过命令行按授权读取或更新数据。接入外部助手前，确认它支持远程 MCP，并按 Google 文档为智能体配置专用 OAuth 客户端。

  • Google Workspace 公告：MCP、CLI 与管理控制
  • Google 开发者文档：配置 Workspace MCP 服务器
  • Google 开发者文档：使用 Workspace CLI

让管理员先确认读写权限

让 Workspace 管理员从管理控制台的安全设置进入 API 控制，查看连接应用、授权范围和适用的确认规则。智能体仍受用户权限和组织策略约束。只做周报时，选用支持只读访问的工具，仅开放任务所需的范围。以后如果要自动发送或更改共享设置，再单独审核这些动作和适用的确认规则。

  • Google Workspace 公告：MCP、CLI 与管理控制
  • Google 开发者文档：配置 Workspace MCP 服务器
  • Google 管理员帮助：控制应用对 Workspace 数据的访问

先用项目周报跑一次小范围试点

例如，选一份已获准访问的 Drive 项目文档，再指定一个项目日历。请助手从文档提取本周决定和待办，从日历补上已排定的时间，并附上来源链接。文档里没有写明的负责人或截止日留空。由项目负责人把纪要与原文核对后，再决定是否把试点扩到邮箱或其他项目。

  • Google 开发者文档：配置 Workspace MCP 服务器

记住两个日期，分别核对接入与计费

2027 年 2 月 1 日起，Google 开始执行面向智能体的 MCP 接入要求，直接调用 Workspace REST API 的智能体受 Standard 层配额限制。2027 年 4 月 1 日起，选择 Scaled 层的项目使用 Gmail、Calendar、Drive MCP 时，按详细计费文档从首个成功请求开始计费。小规模试点可先看项目的 Standard 层配额。接手已有集成时，先确认它的接入方式和所在层级。
