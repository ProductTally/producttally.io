如何用 n8n 筛选多语言稿件并生成审核队列

用三条样例在 n8n 跑通稿件审核队列，核对哪些记录会通过待审条件。

作者 Evan · 更新于 2026年11月11日

本文目录

  1. 先看结论
  2. 导入样例并手动运行
  3. 核对状态规则和输出
  4. 接入自己的队列前再跑一次

先看结论

2026 年 11 月 11 日，我们在本地 n8n 2.46.7 输入三条样例。英文和简体中文稿件状态为 ready，进入输出。西语草稿被筛掉。

下载 n8n 示例工作流（JSON）

n8n 评测

导入样例并手动运行

下载 JSON，在 n8n 的工作流菜单中选择「从文件导入」。打开后手动执行。样例由手动触发器和两个 Code 节点组成，使用虚构记录，无需连接外部账号。

核对状态规则和输出

第一个 Code 节点创建三条记录，每条包含 lang、title 和 status。第二个节点只保留 status 严格等于 ready 的记录，再用 lang 生成示例路径。打开输出，应看到 en 和 zh-CN，西语草稿不在其中。

接入自己的队列前再跑一次

把西语样例的状态从 draft 改为 ready，然后重新运行。预期输出三条。生成的路径是示例字符串。接入自己的网站时，请明确配置各语言对应的真实路径，核对输出后再连接后续步骤。
