先看结论

只想过滤一个受支持浏览器里的网页，先用免费的 AdGuard 扩展。如果还想覆盖其他浏览器或受支持的桌面应用，再考虑 Windows 或 Mac 版，实际范围看系统、应用和设置。Browser Assistant 用于在浏览器里控制桌面版。

先明确你想解决哪一个问题

只在 Firefox 读资料，可以从扩展开始。经常在两个浏览器之间切换，而且确实要过滤一个受支持的桌面应用，才有理由对照桌面版。记下浏览器、应用和你想要完成的操作。

用扩展重复跑三项日常任务

在单独的浏览器配置里用默认过滤设置，读一篇常看网站的文章，登录一个可信的工作网站，再播放嵌入视频或提交自己能控制的测试表单。每项记三个结果：能不能看、能不能完成操作、是否需要给本站做例外。

为了覆盖桌面应用时，先查兼容性

扩展能覆盖日常任务就可以继续用。缺口在浏览器之外时，先确认你的系统、应用和配置能否覆盖。测试桌面版时遵循官方兼容性说明，在浏览器里管理桌面版用 Browser Assistant。配图是两类工作场景的示意。

按剩下的缺口决定买不买

写清付费后需要解决的具体问题和设备数。可信页面如果偶尔异常，可以先只给该站点做例外并重复原操作。如果你的确需要桌面过滤，购买前核对许可证覆盖台数、计费周期和当地结账价。
