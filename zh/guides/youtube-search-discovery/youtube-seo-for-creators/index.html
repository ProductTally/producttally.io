YouTube SEO 实用指南：区分站内搜索与 Google 流量

用 YouTube Studio 了解观众如何在 YouTube 内发现内容，再用已验证的 Search Console 平台资源查看 Google 搜索如何找到你的频道。两类报告回答的是不同问题。

先看结论

先在 YouTube Studio 查看 Trends 和 Analytics，了解观众在 YouTube 上搜索什么、通过哪些入口观看视频；再把频道添加并验证为 Search Console 平台资源，以查看可用时的 Google 搜索、Discover 或 Google 新闻流量。两套数据要分开看：Search Console 不统计 YouTube 站内曝光，任何工具也都不能保证观看量增长。

先分清两个搜索入口，再决定改什么

观众可能通过 YouTube 搜索、推荐、频道页或 Google 搜索发现视频。YouTube Studio 记录 YouTube 内的表现；Search Console 平台资源记录 Google 如何展示频道内容。编辑视频前，先写明你要改善的是哪个入口。Google 点击下降和 YouTube 曝光下降，需要不同的排查方法。

在 YouTube Studio 找到真实的观众问题

打开 YouTube Studio 查看 Analytics，包括流量来源，以及账号中可用时的搜索词报告。Trends 中的 Top searches 卡片依据过去 28 天的受众兴趣和已保存搜索词；“内容缺口”卡片专指 Shorts。部分洞察受国家/地区、语言和设备限制，Studio 界面也在分批更新。把这些数据当作选题线索，而不是完整的关键词搜索量数据库。再结合评论、客服问题和观众正在看的视频核实需求。

让一条视频解决一个明确任务

写标题前，先用一句话描述观众要完成的事：学会一个流程、比较两个选项，或解决一个具体问题。把核心词自然地放进准确、简洁的标题，并在视频前段说明能获得什么。缩略图应与实际内容一致。YouTube 建议标题和缩略图准确；重复堆词或夸大承诺会让观众失望，不能替代有用的视频。

把频道添加为 Search Console 平台资源

在 Search Console 中选择平台资源选项添加 YouTube 频道，并完成所有权验证。如果管理多个频道，需要分别添加。Google 表示该功能正在逐步开放，数据可能需要几天才会出现。如果暂时没有该资源或还没有数据，不要把它理解为 YouTube 触达为零；站内表现继续以 YouTube Studio 为准。

把 Google 的发现数据当作 Google 数据

在已验证的资源中，通过效果报告按查询、页面、国家/地区、设备和日期查看数据。只有频道从 Discover 或 Google 新闻获得流量时，相关报告才会出现。如果频道同时发布长视频和 Shorts，可以对比网址中包含 `/watch` 与 `/shorts/` 的页面，区分它们从 Google 搜索获得的流量。该报告可帮助你找出值得复查的视频或查询，但不展示 YouTube 曝光、YouTube 搜索排名或完整的观众行为。比较变化时保持日期范围和流量入口一致。

保留简短的改动记录，再决定下一步

每次复查记录日期范围、入口、查询、视频网址、观察到的信号、本次只做的一项改动和复查日期。如果 YouTube 搜索曝光较弱，检查观众问题、标题是否准确，以及视频是否真正回答了问题；如果 Google 点击较弱，检查 Google 查询和视频在搜索结果中的呈现；如果触达稳定但观众很快离开，就在 YouTube Analytics 查看开场和留存。不要一次同时改标题、缩略图和视频结构；简单记录能帮助判断变化来自哪里。
