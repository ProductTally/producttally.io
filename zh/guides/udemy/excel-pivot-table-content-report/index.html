先看结论

如果你想把内容平台导出的明细变成一份能交给同事更新的周报，可以在 Udemy 选讲数据透视表的 Excel 课程。优先看课程有没有练习文件、是否讲源数据准备、是否演示刷新。先用六行样例验收，再套到自己的数据上。

Udemy 评测

用六行样例做一份周报

建日期、渠道、浏览量三列。填六条虚构内容，邮件 120 和 80，博客 90 和 60，视频 70 和 50。保持一行表头、每条内容独占一行，浏览量用数值格式。把源数据转换成 Excel 表格，再插入数据透视表，把渠道放到行、浏览量放到值，并确认汇总方式是求和。

用两个总数定位错误

预期邮件 200、博客 150、视频 120，合计 470。如果每个渠道只显示 2，先检查浏览量是否被当成文本，或者「值」使用了计数。再给源表加一行邮件 30，刷新后邮件应为 230、合计应为 500。把源表和汇总保存在同一个工作簿，让接手的人也能复现。

拿验收结果回看课程大纲

在 Udemy 搜索「Excel 数据透视表」或 “Excel PivotTables data analysis”。试听时看讲师有没有从整理源表开始，以及 Excel 版本和平台是否与你相符。日常从 CSV 做周报的话，优先看课程是否涵盖导入与检查。选提供练习文件、能完整复现刷新流程的课程，再核对当地价格或套餐是否包含。
