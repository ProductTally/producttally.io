用 SEOPress 免费版设置 WordPress SEO 标题并验证 noindex

给单个 WordPress 页面保存 SEO 标题和描述后，可以打开 HTML 源码和 XML 站点地图核对结果。如果某个功能页本来就不希望出现在搜索结果中，再启用 noindex 并复查这两处。

先看结论

2026 年 11 月 11 日，我们在本机的临时 WordPress Playground 站点上完成了这套操作。测试环境为 WordPress 7.1.4、PHP 8.3 和 SEOPress Free 10.4，编辑器使用英文，页面只包含合成测试文案。

SEOPress 评测

保存 SEO 标题和描述

在 WordPress 页面编辑器中打开 SEOPress 工具栏，进入 Titles & Metas。填写能概括页面内容的标题和简短描述，保存 SEO 设置及页面。

打开生成的页面并查看 HTML 源码。找到 <title> 和 name="description"，核对是否与刚保存的内容一致。再检查 rel="canonical" 指向哪个网址。本次测试指向页面自身。

对照浏览器标签页标题与正文标题。我们设置的 SEO 标题是 “Workshop checklist for solo creators | QA”，正文 H1 仍为 “Workshop checklist QA”。SEOPress 的预览适合编辑时核对文字，实际输出以页面源码为准。

启用 noindex 前后各检查一次站点地图

确认 SEO → XML–HTML Sitemap 已启用 XML 站点地图。打开站点地图索引，再进入页面分表。本机测试生成的是 page-sitemap1.xml。在分表中搜索页面网址，确认它已列出。

回到你明确希望排除出搜索结果的功能页，在 SEOPress 的 Advanced 面板勾选页面级 noindex，然后保存。

重新打开页面源码并核对 robots 元标签。实测输出为 follow, noindex，原先设置的 SEO 标题和描述仍在。刷新站点地图分表后，测试页已移除，默认示例页仍然列出。

本次核对的是本机生成的 HTML 和 XML。实际抓取、索引、排名、插件迁移和 PRO 功能都在测试范围之外。线上页面需要允许 Googlebot 访问，Google 才能读取 noindex 指令。
