WordPress 改了文章链接，怎么用 SEOPress PRO 做 301 重定向？

用一条旧网址和一条新网址配置 SEOPress PRO，检查 301、最终 200、站内链接和站点地图。

作者 Evan · 更新于 2026年11月13日

本文目录

  1. 先看结论
  2. 先让新页可访问，再建规则
  3. 分别检查旧地址和新地址

先看结论

同一篇 WordPress 文章永久换网址时，可以在 SEOPress PRO 把旧相对路径指向完整的新 HTTPS 地址。验收时，旧地址应返回 301，直接跳到返回 200 的新页面。这样读者从书签或外链打开旧地址时，仍能找到原来的内容。

SEOPress 评测

先让新页可访问，再建规则

假设旧地址是 /guides/old-post/，新地址是 https://example.com/guides/new-post/。先确认新页已发布。进入 WordPress 后台的 SEO → PRO → Redirections / 404，启用重定向，再在 SEO → Redirections 新建规则。来源填 guides/old-post，目标填完整的新网址，类型选 301，登录条件选 All，启用并保存。只改一篇时用单条路径规则。

分别检查旧地址和新地址

退出登录后打开旧地址，或用 curl -sS -o /dev/null -D - https://example.com/guides/old-post/ 查看第一跳。预期是 301，Location 指向新网址。再单独请求新地址，确认返回 200。若中间还有一跳，检查插件是否有重复规则、WordPress 是否在规范化网址，以及 CDN 是否另有配置。如果仍看到旧响应，清除对应缓存后再测。

把能改的链接换成新地址

更新正文、菜单或目录里指向旧地址的站内链接，并核对新页面的 canonical。如果这篇文章应被索引，确认 sitemap 收录的是新地址。旧链接带 UTM 时，再用一个样例查询串检查需要的参数是否传到了新页。保留这条 301 承接旧外链，其他没有对应内容的下线页面单独处理。
