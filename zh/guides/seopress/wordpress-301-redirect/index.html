WordPress 改了文章链接，怎么用 SEOPress PRO 做 301 重定向？

用一条旧网址和一条新网址配置 SEOPress PRO，检查 301、最终 200、站内链接和站点地图。

作者 Evan · 更新于 2026年11月16日

本文目录

  1. 先看结论
  2. 先让新页可访问，再建规则
  3. 用两次 GET 看清第一跳和最终页

先看结论

同一篇 WordPress 文章永久换网址时，可以在 SEOPress PRO 把旧相对路径指向完整的新 HTTPS 地址。验收时，旧地址应返回 301，直接跳到返回 200 的新页面。这样读者从书签或外链打开旧地址时，仍能找到原来的内容。

SEOPress 评测

先让新页可访问，再建规则

假设旧地址是 /guides/old-post/，新地址是 https://example.com/guides/new-post/。先确认新页已发布。进入 WordPress 后台的 SEO → PRO → Redirections / 404，启用重定向，再在 SEO → Redirections 新建规则。来源填 guides/old-post，目标填完整的新网址，类型选 301，登录条件选 All，启用并保存。只改一篇时用单条路径规则。

用两次 GET 看清第一跳和最终页

先用 curl -sS -o /dev/null -D - https://example.com/guides/old-post/ 查看第一跳，再加 -L 看两次响应。本地 HTTP 验收样例中，旧页返回 301，Location 为 /guides/new-post/?utm_source=qa，一跳到达返回 200 的新页。新页源码的 canonical 指向不带参数的 /guides/new-post/。这次验证的是 HTTP 行为，SEOPress PRO 的配置步骤来自官方文档。

用旧推广链接检查参数，再检查网站引用

如果旧活动链接上的 UTM 仍要保留，在 SEOPress 选匹配时忽略查询参数、跳转时传给目标页的选项。加 ?utm_source=qa 测一次，对照最终地址与 canonical。把能更新的站内链接改到新地址，这篇文章的 sitemap 只留新规范网址。若第一跳是 404 或跳了多次，检查规则是否启用、尾斜杠和 CDN 缓存。
