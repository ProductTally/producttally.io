同じ一行を変えた二人の意図を読み取る

練習用のローカルリポジトリで「金曜日に公開する」というREADMEをコミットします。同じコミットから2つのブランチを作り、片方で「木曜日に公開する」、もう片方で「スペイン語版を金曜日に公開する」に変更して、それぞれコミットします。最初のブランチに戻り、もう片方をマージします。

git status で対象ファイルを探し、マーカーで分かれた2つの文を確認します。木曜日への変更がスペイン語版にも適用されるなら、「スペイン語版を木曜日に公開する」とまとめられます。日付が不明なら担当者に聞きます。

コミット予定の内容を確認する

競合マーカーを取り除いて文を修正し、git add README.md と git diff --cached を実行します。言語と日付が揃っていることを確かめ、git commit でマージを完了して状態を確認します。プルリクエストでレビューするなら、両方の変更をどう残したか説明します。

Udemyの *Git & GitHub – The Practical Guide* には、VS Codeでの競合解消、git diff での比較、プルリクエストのレビューが含まれます。プレビューでは、競合を解消した後に最終内容をどう確認するかを見ましょう。
