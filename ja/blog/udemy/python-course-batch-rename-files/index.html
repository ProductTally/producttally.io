変更する前に一覧を出す

フォルダーをコピーし、notes.txtも一緒に入れます。JPEGだけを対象に、DSC_0041.jpgからstudio-001.jpgのように、元と先を1行ずつ出します。拡張子は維持し、テキストの名前は変えません。複数のカメラの素材が混じるときは、一覧で順序も確認できます。
