顧客の「金曜を目指す」をSembly AIで確かめて引き継ぐ

議事録から発言に戻り、担当者、返答の期限、公開に必要な承認を確認します。

によって Evan · 更新日 2026/11/17

  2. 金曜の話を三つに分けて書く
  3. 文字起こしが必要な人にだけ共有する
  4. 許可のある短い会議で試す

開発担当は金曜公開で予定を取り、デザイナーは法務の返事を待っています。二人が読んだ議事録は同じです。Sembly AIは議事録と要点、検索できる文字起こしをまとめて見られるので、どんな条件が付いていたかを発言まで戻って確認できます。

まず公式デモで一つの発言を見つける

Semblyの公式デモの Bookmarks で Northwind pricing review の11:55を探します。発言は月額の変更と年額の据え置きを区別しています。実際の会議では Key Item から前後の発言を読み、話者や言い回しが曖昧なら録音を聞き直します。

金曜の話を三つに分けて書く

架空の会議を例にします。09:21に運用担当が「決済ページの確認が済めば、金曜に10人を招待したいです」と話しました。09:36に責任者が「金曜はまだ決めません。Alex、明日の午後までに決済ページを確認して報告してください」と答えました。

引き継ぎ例
場所記録
顧客向け金曜に10人を招待する案。決済ページの確認結果を待つ。
社内タスクAlexが明日の午後までに決済ページを確認して報告する。タスクの登録時には日付とタイムゾーンも記入する。
保留責任者が決済ページの確認結果を見て、試用日を決める。

議事録を直したら、Key Items、割り当て済みのタスク、顧客向けの要約に同じ誤りが残っていないか確認します。すでにプロジェクト管理ツールへ転記した内容も訂正します。

時刻付きの Key Items にカーソルを合わせ、リンクをコピーします。正しい発言に移動するか確かめてから、閲覧権限がある人に送ります。

文字起こしが必要な人にだけ共有する

ゲストリンクでは録音や文字起こし、要点が見えることがあります。相手に日付を確認してほしいだけなら、確認済みの要約を送ります。

  • Semblyのゲストリンクと発言リンク

許可のある短い会議で試す

別の参加者に引き継ぎだけを渡し、条件、担当者、締切を説明できるかを確認します。分からない箇所は元の発言に戻るか、確認待ちとして残します。
