PDF2Go でサイズの異なる添付書類を1本の PDF にまとめる

提出先が1ファイルのみ受け付けるとき、表紙・本文・横長の別紙を順番にまとめます。

によって Evan · 公開日 2026/11/28 · 更新日 2026/11/28

PDF2Go の Merge PDF に提出順でファイルを並べます。横長の表に幅が必要なら元のページサイズを維持し、提出先が用紙を指定しているなら出力サイズと向きを統一します。公式ページによると、アカウントなしの場合のアップロード上限は50 MBです。

一番幅の広いページを縦に統一するか考える

学会の提出書類が表紙、本文、横長の予算表で構成され、提出できる PDF は1本とします。まず募集要項を読んで、混在サイズが認められていれば別紙の向きを維持し、項目名と右端の合計を読みやすくします。統一が必要なら出力設定を使い、完成版を通常の倍率で開いて表を確認します。

ファイルの境目を確認してから提出する

元の名前に 01、02、03 を付け、アップロード後に正しい順でドラッグします。結合した PDF は元ファイルの合計ページ数と照らし合わせ、各書類の最初のページと、幅の広い表の右端まで確認します。オンライン処理が認められている書類なら、提出前に添付の漏れや順序違いを見つける簡単な方法です。
