WordPressの記事スラッグを変えたらSEOPressで301を設定する

旧URLから新しい記事へ直接案内し、訪問者が通る経路を確認します。

によって Evan · 更新日 2026/11/20

同じ記事を恒久的に移す場合は、旧URLから新URLへ直接リダイレクトします。例えば /blog/old-workshop/ を /blog/workshop-checklist/ に移すなら、新旧の完全なURL、担当者、変更日を記録します。

SEOPress · 製品の詳細を見る

旧パスにルールを1件作る

リダイレクト管理はSEOPress PROの機能です。SEO → Redirectionsでルールを作り、Origin URLに旧相対パス、宛先に新しい完全なURLを入力します。301を選択して有効にし、Test URLを使います。旧URLにキャンペーン用パラメータがある場合は、引き継ぐか決めて該当する条件で確認します。

  • Setting up redirections
  • SEOPress PRO redirect manager

訪問者として経路を確認する

ログアウトした状態で旧URLを開き、新ページに直接移動して200が返るか確かめます。管理できるリンクとサイトマップを新しい正規URLに差し替え、チームにも共有します。旧アドレスを保存した訪問者向けに301は残します。
