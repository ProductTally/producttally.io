SEOPressのサイトマップに著者、添付、社内向けのURLが出るときは？

著者アーカイブ、添付ページ、ファイル、非公開ページを切り分け、実際のレスポンスを確認します。

によって Evan · 更新日 2026/11/18

サイトマップのインデックスを開き、該当URLが載る子サイトマップを見ます。著者アーカイブ、添付ページ、画像やPDFの直リンク、通常のページを切り分けます。SEOPressでは投稿やページのSEOメタボックスの詳細設定でnoindexを付けると、XMLサイトマップから除外できます。以前共有されたリンクからは開けることがあります。

ログアウトしたブラウザーで元のURLを開く

見積もりをサイトマップから消しても、古いメールからPDFが開くことがあります。直リンクの権限も確認します。公開PDFを検索結果から除外したい場合は、クローラーが応答を読める状態で X-Robots-Tag に noindex を指定できます。社内向けのファイルにはアクセス制御を使います。応答、子サイトマップ、リンク元をそれぞれ確認します。

  • Googleのrobots指定

SEO → XML – HTML Sitemapのリンクから実際のインデックスを開き、Post Types & Taxonomiesで対象の種類を確認します。ページ1件を変更したら、対応する子XMLを開き直して完全なURLを探します。直接ファイルなら、そのHTTPレスポンスも確認します。

キャッシュに古いXMLがあれば更新します。新しいサイトマップを送信したら、Search Consoleのクロールとインデックスの状態を照合します。サイトマップから消えたか、訪問者に開けるか、検索でどう扱われるかを別々に確認します。
