Gammaの資料のデザインをワークスペースのテーマにするタイミング

顧客ごとのスタイルを資料に残し、別案件でも使える見た目だけを共有します。

によって Evan · 更新日 2026/11/20

GammaのStylesは個別の資料に適用され、Themeはワークスペースで再利用できます。顧客専用の配色や文字組みを調整するときはStylesを使います。他の案件でも使う目的があり、フォントや画像を再利用する権利があるときにテーマ化します。

Gamma · 製品の詳細を見る

再利用できる見た目を取り出す

自社フォントと顧客ロゴを合わせた提案なら、資料を複製し、顧客の素材を取り除いてからサンプルを作ります。長い見出し、2列のカード、色付きのブロックに置いたリンクを確認します。その後、Styles → Themes → Save as new themeで保存します。

チームにテーマを渡す

既存のテーマと区別できる名前を付け、最初に使う資料を決めます。ブランド設定などの条件はGammaの料金ページで確かめます。チームには、共通の設定と案件ごとに変えてよい設定を短いメモで渡します。
