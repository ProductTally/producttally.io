Teachableで役割ごとにどこまでアクセスを許可する？

講座編集、学習進捗、財務を分けて、役割ごとのテストアカウントで確認します。

によって Evan · 更新日 2026/11/17

担当者の作業を整理し、Settings → Roles を開きます。既定の役割で足りるか確認し、細かい権限が必要なら契約とアカウントの選択肢を照合します。

役割ごとにアクセスを確認する

検証する権限の例
担当必要な作業追加で確認する範囲
講師対象講座の編集と教材の確認他の講座や財務情報
アシスタント担当受講者の進捗と承認済み経路での講評編集、名簿の出力、他クラス
運営受講登録、アカウント、必要な決済対応返金、売上、管理者枠

新しいTypes of User RolesではカスタムロールをGrowth以上で作成できると説明しています。Custom User RolesにはBusinessの表記が残っています。現在の料金ページを見て、学校のSettings → Rolesに必要な設定があるか確認します。表は権限の確認項目です。

Teachable公式ヘルプの「Types of User Roles」と「Admins」、および「Custom User Roles」を参照しました。

役割ごとにテストアカウントを使う

役割ごとに試験アカウントを用意し、必要な画面と制限対象の画面を開きます。アシスタントに広い権限を付けないとできない作業は、その権限を持つ担当者へ分けます。日付、役割、結果を記録し、人員変更後にも再確認します。
