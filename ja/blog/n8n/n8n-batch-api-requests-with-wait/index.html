n8nのLoop Over ItemsとWaitでAPIリクエストを分割する

スプレッドシートのデータを、接続先が許容するペースで業務システムに取り込みます。

によって Evan · 更新日 2026/11/24

接続先のAPIに上限がある場合は、Loop Over ItemsとWaitでバッチ間隔を空けます。短い中断にはRetry On Failが使えます。設定前に、APIの上限と一行から発生するリクエスト数を確認します。

行数とリクエスト数を確認する

承認済みの商品100件を社内カタログに取り込むとします。1行1回の書き込みで上限が毎分60件なら、10件を送って15秒待つ例では毎分約40件です。他の処理は含めていません。同じ上限のもとで毎行の検索も行うなら、必要なリクエストは増えます。

接続先が認証情報単位、移動する時間枠など、どの方式で数えるかを確認します。共有認証情報を使う処理の分も余裕を残し、429が出たら上限と送信の偏りを見直します。

途中で止まっても続けられるようにする

バッチをリクエストのノードにつなぎ、Waitを経由してループに戻します。短い中断で繰り返しても安全なときにRetry On Failを使います。新規作成には、接続先が対応していれば安定したキーやアップサートを使います。

レコードごとの結果を保存し、未処理のものだけ再実行します。タイムアウトした書き込みが反映済みの可能性があるなら、先に現在のカタログを確認します。
