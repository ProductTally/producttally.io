HelpCrunch でスペイン語のヘルプ記事を公開する順番

言語選択からカテゴリ、セクション、記事まで、利用者が迷わないように整えます。

によって Evan · 公開日 2026/11/28 · 更新日 2026/11/28

HelpCrunch の翻訳は主言語の記事にひも付きます。まず原文を公開し、翻訳言語の設定にスペイン語を追加します。スペイン語の記事を保存・公開する前に、そのカテゴリとセクションを翻訳します。

これらのリンクから購入すると、ProductTally が紹介手数料を受け取る場合があります。

すでに読まれている案内を一つ選ぶ

例として、請求先メールアドレスの変更方法を選びます。原文に実際の画面で使われている項目名が載っているか確認します。Knowledge Base → Settings → Languages for translation でスペイン語を追加し、スペイン語版のヘルプセンター名を登録します。

  • 多言語ナレッジベースの設定

記事へたどり着くまでの階層も翻訳する

原文を開いて編集画面の言語をスペイン語に切り替えます。記事に加えてカテゴリとセクションを翻訳すると、スペイン語版のトップから案内まで探せます。未翻訳の階層がある場合は保存前に案内が出ます。画像の説明とリンク先もスペイン語の読者が使えるか確認します。

  • 多言語ナレッジベースの設定

公開したヘルプセンターから開く

訪問者向けの言語選択でスペイン語に切り替え、カテゴリから記事まで進みます。残った翻訳は Translation Report で把握できます。主言語の記事を無効にすると翻訳もすべて無効になるため、公開を続けたい間は原文も有効にします。

  • 多言語ナレッジベースの設定
