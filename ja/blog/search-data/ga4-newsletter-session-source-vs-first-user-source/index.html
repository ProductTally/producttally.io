メルマガで再訪した読者を GA4 で見るなら、どちらの参照元？

同じ読者の初回訪問と再訪を追い、メール施策に合った GA4 レポートを選びます。

によって Evan · 公開日 2026/11/28 · 更新日 2026/11/28

メルマガ経由の訪問数は「トラフィック獲得」のセッションの参照元 / メディアで確認します。利用者が最初にサイトを見つけた経路は「ユーザー獲得」の初回ユーザーの参照元 / メディアで確認します。同じ人でも二つの参照元は異なることがあります。

獲得レポートの比較 · 参照元のスコープ

月曜は自然検索、金曜はメルマガから

月曜に自然検索でテンプレート販売サイトを見つけた読者が、金曜にメールで戻ったとします。リンクには utm_source=maker_weekly と utm_medium=email を付けます。GA4 が同じ利用者と認識し、別セッションを記録した例では、初回参照元は自然検索、金曜のセッション参照元はメールです。

  • 参照元のスコープ

金曜の配信で増えたアクセスを確認する

「トラフィック獲得」で配信期間を指定し、セッションの参照元 / メディアを確認します。同じ配信元で複数の企画を実施したなら「セッションのキャンペーン」で分けます。メール同士を比べるときは、同じディメンションと期間の考え方でセッション数をそろえます。新規利用者の最初の流入は「ユーザー獲得」で別に読みます。

  • 獲得レポートの比較
  • 参照元のスコープ

集計名を「メール経由のセッション数」にする

週報には maker_weekly / email に帰属したセッション数と書きます。購入への貢献が知りたいなら、キーイベントのレポートとアトリビューションモデルを改めて確認します。セッションの発生源と購入の貢献度は集計範囲が違います。
