WordPressのURL変更後にSEOPress PROで301リダイレクトを設定する方法

旧URLから新URLへ転送し、HTTP応答、内部リンク、サイトマップを確認します。

によって Evan · 更新日 2026/11/13

この記事の目次

  1. 結論
  2. 転送元と転送先を登録する
  3. 最初の応答と到達先を確認する
  4. 更新できる参照を新URLに切り替える

結論

同じ記事のURLを恒久的に変更する場合は、SEOPress PROで301を設定します。旧URLの相対パスを新しいHTTPSの完全なURLに結び付けます。旧URLが301を返し、新URLに直接移動して200になることを確認します。

SEOPress のレビュー

転送元と転送先を登録する

例として /guides/old-post/ を https://example.com/guides/new-post/ に変更します。新しい記事を公開してから、SEO → PRO → Redirections / 404 でリダイレクトを有効にします。SEO → Redirectionsで、転送元 guides/old-post、転送先の完全なURL、種類301、ログイン条件Allを指定します。有効にした状態で保存し、まず対象記事だけに適用します。

最初の応答と到達先を確認する

ログアウト状態で旧URLを開くか、curl -sS -o /dev/null -D - https://example.com/guides/old-post/ を実行します。301とLocationの値を確認し、新URLには別にアクセスして200を確認します。途中の転送がある場合は、別のルール、WordPressのURL正規化、CDNの設定を調べます。古い応答がキャッシュされていれば、対象のキャッシュを消して再確認します。

更新できる参照を新URLに切り替える

内部リンクと新ページのcanonicalを確認します。インデックス対象の記事はサイトマップに新URLが載っているか確認します。キャンペーン用のクエリが必要なら、サンプルのパラメーター付きURLも試します。既存の外部リンクに備えて転送を残し、内容の異なる削除済みページはこの転送先にまとめないようにします。
