結論

CSV週報を自動化するなら、列名による読み込み、異常行の検出、再実行しても同じ出力になる処理を扱う講座を選びます。Python 3.9.6の練習では、3行からBlog 8とEmail 17を集計できました。N/Aを追加すると処理は止まり、前回の出力が残りました。

3行の練習用CSVをダウンロード

Udemy のレビュー

3行を読み込み、別のファイルに書き出す

weekly-clicks.csvをダウンロードします。UTF-8で開き、newlineに空文字列を指定して、csv.DictReaderでchannelとclicksを読みます。クリック数を整数に変換してチャンネル別に合計し、csv.DictWriterでreport.csvに同じ見出しを書きます。チャンネル順はBlog 8、Email 17で、合計25です。入力は別に保存します。

異常行で前回の出力が残るか確かめる

入力のコピーの末尾にBlog,N/Aを足します。report.csvを書き込み用に開く前に、全行を検証します。整数変換に失敗した場合は5行目と表示して終了します。検証では以前の結果が残りました。異常行を消して2回実行すると、出力は毎回同じ2件で、重複はありません。

足りない知識を講座や書籍で補う

Pythonの導入、最初のプログラム、デバッグから学ぶなら、UdemyのAl Sweigartの公開目次が参考になります。このCSV課題を扱うことは公開ページでは確認できませんでした。著者が別に公開している書籍の章でCSVの読み書きを学べます。ループと辞書を知っているなら、まずその章で練習し、手順を追って学びたい場合は異常入力と再実行も扱う講座を選びます。独自のサンプルを実行して確認しました。
