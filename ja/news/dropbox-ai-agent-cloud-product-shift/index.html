DropboxがDBX Agent Cloudを発表：Tigrisのオブジェクトストレージは誰向け？

DropboxはファイルワークスペースにAI操作を加え、DBX Agent Cloudは開発者向けのS3互換オブジェクトストレージから始まります。

2026年11月のDropboxの発表では、関連はあるものの用途の異なる2つの製品が説明されています。既存ファイルを扱うチーム向けのAI対応Dropboxワークスペースと、AIアプリを開発する企業・開発者向けのストレージおよびデータ基盤DBX Agent Cloudです。Dropboxは11月17日にTigrisの買収を完了したと発表しました。DropboxのファイルワークスペースはSaaSです。Tigrisは開発者向けのマネージドクラウド・オブジェクトストレージと呼ぶのが正確です。どちらもオンラインで提供されますが、解決する課題は異なります。

1社の中にある、2つの製品用途

新しいDropbox体験は、使い慣れたファイル保管・共同作業のワークスペースに、AI検索やファイル操作を加えます。一方、DBX Agent Cloudはインフラの新しい方向性です。Dropboxによると、まず単独で購入できるオブジェクトストレージを提供し、企業は選んだクラウドやコンピューティング環境と組み合わせられます。Tigrisの買収は開発者向けのこの方向に関わるもので、普段使うDropboxフォルダの用途が変わるわけではありません。

  • Dropboxの次の展開とDBX Agent Cloud

新しいDropbox体験でチームができること

Dropboxによると、ファイルへの質問、フォルダの要約、バージョン比較、文書の下書き、PDFや画像の編集、録音の文字起こし、ファイルの整理・名前変更ができます。対応する変更を実行する前に計画を提示して承認を求めます。操作は既存のアクセス権に従い、履歴を確認したり、対応する変更を取り消したりできます。

提供条件も確認しましょう。Dropboxの11月17日の更新によると、初期提供の対象は米国・英国・オーストラリアの対象となるStandardおよびAdvancedチームで、まず英語から始まります。Dropboxは7万以上のチームに提供済みとし、2027年に対象を広げる予定です。管理者向けガイドでは、AI体験はStandardとAdvancedに含まれますが、チャットのリクエストやAI操作はチームのAIクレジットを使用すると説明されています。共同作業の計画前に利用可否と残りのクレジットを確認してください。

開発者にとってのTigris

Tigrisは、複数のクラウドや計算環境で動くアプリ向けのS3互換オブジェクトストレージとして自社製品を説明しています。AWS SDKやAWS CLI、boto3などの使い慣れたツールで接続できます。Dropboxによると、DBX Agent Cloudは単独購入できるオブジェクトストレージから始まります。ファイルシステムやコンテンツ処理の機能は今後追加する計画であり、すでに使える機能として扱わないでください。

アプリやAIエージェントを開発し、ファイル、データセット、生成メディアを継続的に保存するチームにTigrisは関係します。マネージドクラウドサービスですが、製品カテゴリはクリエイター向けの汎用業務SaaSではなく、開発者向けのインフラストレージです。

小規模チームはどちらを検討すべき？

すでにDropboxでファイルを管理しているチームは、新しい体験が使えるか、対象プランはどれか、AIクレジットがどう共有されるかを確認しましょう。まず影響の小さいフォルダで試し、承認前に提案された操作を見直します。

AIアプリを開発しているなら、TigrisまたはDBX Agent Cloudをストレージ要件と照らし合わせます。S3 APIとの互換性、計算環境の場所、アクセス制御、現在の料金、現時点で利用できる機能を確認してください。発表されたロードマップだけで判断しないことが大切です。要点は、Dropboxのワークスペースは人がファイルを扱うためのもの、Tigrisは開発者がソフトウェアに組み込むオブジェクトストレージだということです。
