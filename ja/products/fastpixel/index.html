主な機能

  • ページキャッシュ、HTML・CSS・JavaScript の縮小、Critical CSS、CDN 配信を組み合わせています。
  • 画像には ShortPixel 技術を使用し、サイズ調整、遅延読み込み、WebP の自動配信に対応します。
  • ページと JavaScript の除外設定で、指定したページやスクリプトを最適化の対象外にできます。
  • Free Plan は 1 サイト、月間 1,000 ページビューまでです。有料プランはページビュー数とサイト数の枠が増えます。

選ぶ理由

  • WordPress の一つのプラグインでキャッシュとフロントエンド資源の最適化を管理できます。
  • 画像を個別に書き出さずに最適化し、CDN から配信できます。
  • 元の動作を保ちたいページやスクリプトは除外できます。

使い始めるには

  1. WordPress のプラグイン画面で FastPixel Website Accelerator を検索し、インストールして有効化します。案内に沿ってアカウントを接続します。
  2. FastPixel の設定を開き、ページ、画像、JavaScript の項目を確認します。元の状態を保つページやスクリプトは除外します。
  3. キャッシュ状態を確認し、Stale のページは Cache Now で処理します。キャッシュ後の表示を調べ、資源のキャッシュが整ってから速度を確認します。
