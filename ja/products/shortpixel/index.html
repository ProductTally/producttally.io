主な機能

  • WordPress プラグインで既存のメディアライブラリを一括最適化し、新しい画像も処理できます。
  • Lossless、Glossy、Lossy を選び、WebP・AVIF 版を作成できます。JPEG、PNG、GIF、PDF の最適化に対応しています。
  • 無料枠は毎月 100 最適化クレジットです。サムネイルも消費するため、一回のアップロードで複数クレジットを使う場合があります。

ShortPixel Image Optimizer の公式機能紹介 ShortPixel の最新プラン・買い切りクレジット 公式 FAQ：設定・クレジット・バックアップ

選ぶ理由

  • ファイルを個別に書き出さず、WordPress 内で既存ライブラリを処理できます。
  • 画質保持を優先する場合は Lossless を選び、Glossy や Lossy と容量・画質を比較できます。
  • 既存画像の整理には期限のない買い切りクレジット、継続的な作業には定期プランを検討できます。

使い始めるには

  1. WordPress で ShortPixel Image Optimizer をインストールして有効化し、設定画面で自分の API キーを入力・検証します。
  2. 圧縮方法と元画像のバックアップ設定を選びます。まず写真と図版を少数処理し、表示を確認します。
  3. メディア > Bulk ShortPixel から残りを処理します。必要クレジットにはサムネイルも含め、最適化後にサイトのキャッシュを消去します。

一括処理の前に、対象画像、圧縮方法、バックアップの有無、予想クレジット消費をプラグインで確認しましょう。
