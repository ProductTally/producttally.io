How to sell Canva templates on Payhip: the delivery PDF a buyer can actually use

Build a one-page media-kit handoff and rehearse the purchase from a separate Canva account.

By Evan · Updated Nov 16, 2026

On this page

  1. Quick answer
  2. Write the one-page handoff before opening Payhip
  3. Run the test as an outside buyer
  4. Find the broken step before taking orders

Quick answer

Upload a one-page PDF with a Canva Template link as your Payhip digital product. The buyer should be able to open the receipt, download the PDF and edit their own copy in Canva. A zero-charge coupon order can rehearse delivery. Payment processing requires a separate test.

Payhip Review

Write the one-page handoff before opening Payhip

For a three-page media kit, list the cover, audience stats and contact page. Label the button “Open your Canva template.” Add these directions: “Sign in to Canva, use the template to create your copy, replace the sample numbers and export a PDF.” Insert your own working Template link and test it in the exported PDF. Canva limits who can create Template links to eligible plans. If you use Pro assets, check Canva’s licensing rules and test export from the buyer’s expected account type.

Run the test as an outside buyer

Create a Payhip Digital Product with the PDF and previews of the included pages. Set it to Unlisted for the rehearsal. Anyone with the direct link can still open it. Use a product-specific 100% coupon with one use and a test email you control. Open the order confirmation and the receipt in a clean browser. Sign in to Canva with an account outside the design team and change the contact line in its copy. Verify your original stays unchanged.

Find the broken step before taking orders

If the receipt opens the wrong file, replace the Payhip delivery PDF. If the PDF opens the original design or prompts for access, replace the link with the Canva Template link and test it from outside your workspace. If a Free buyer sees a paid-asset prompt, replace that element or state the requirement before purchase. Disable the test coupon after use. This example is a proposed check based on the vendors’ docs.
