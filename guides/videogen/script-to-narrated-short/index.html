How to make a narrated short from a script in VideoGen

Set up a short script, review narration and captions, and estimate generation credits separately from export.

By Evan · Updated Nov 11, 2026

On this page

  1. Quick answer
  2. Write a short script and choose the format
  3. Review the preview before regenerating clips
  4. Check export access and cost separately

Quick answer

In VideoGen, open Script to video, add the script and choose a format, narrator and visual style. Review pronunciation, captions and pacing before exporting. The official rate card lists generation charges separately from export charges.

VideoGen Review

Write a short script and choose the format

Use one idea per paragraph for a short explainer. Pick the aspect ratio for the intended channel, choose a narrator and decide whether the draft needs generated clips or can use stills and library footage. Check the caption settings before building.

Review the preview before regenerating clips

Watch for mispronounced names, caption errors and visuals that do not match the narration. Correct the text before regenerating a scene. At the listed Standard rate of 20 credits per generated second, two 10-second clips would use 400 credits for generation alone.

Check export access and cost separately

The published rate card lists zero export credits up to 1080p and two credits per output second at 4K. Export still depends on plan eligibility. A 30-second 4K output would use 60 export credits under that rate. Confirm the plan and export settings before delivering an MP4.
