Adobe Firefly Creative Agent vs Firefly Graph: a workflow for small teams

Use one product photo to decide when to use Quick Actions, Plan Mode or Firefly Graph. Includes a practical pilot and the availability Adobe announced at MAX 2026.

By Evan · Updated Nov 11, 2026

On this page

  1. Quick answer
  2. Start with one photo and two deliverables
  3. Choose the simplest path for the job
  4. Turn the sequence into a reusable Graph
  5. Review the exported files before using them
  6. Keep Builder separate from asset production

Quick answer

Use Quick Actions for a supported one-off edit, Firefly AI Assistant with Plan Mode to review a proposed sequence, and Firefly Graph to test a repeatable workflow. Adobe lists AI Assistant and Graph as beta and Builder as a private beta with a waitlist. This guide uses Adobe’s November 10 announcement; the pilot below is a suggested exercise.

Start with one photo and two deliverables

Pick a product photo you have permission to use. Keep the original as a reference. Brief: make a square social image and a vertical story image; preserve the product’s color and shape, use a clean background, leave room for a headline, and add no new text or logos. List the two outputs before choosing a tool.

Choose the simplest path for the job

If the task is just a supported edit such as relighting, use the corresponding editor action. Adobe lists Edit Text, Retouch, Relight and Quick Actions as generally available. For a sequence that needs creative decisions, ask AI Assistant for a plan and review it before generation if Plan Mode is available. Specify which steps require approval.

Turn the sequence into a reusable Graph

If your account has Firefly Graph, plan four stages: original image, background treatment, square and vertical variants, and human review. Treat the original and the aspect ratios as inputs. Try two photos in separate runs and check whether you can swap the input without rebuilding the workflow. Record the model, retries and manual edits for each run.

Review the exported files before using them

Compare both outputs with the original at actual display size. Check edges, color, label legibility and cropping, then preview each file in its intended placement. Track elapsed time and credits, if visible. Compare with your usual editor before deciding whether a reusable Graph saves work. A single successful image is insufficient evidence for batch use.

Keep Builder separate from asset production

Adobe describes Firefly Builder as a private beta for interactive prototypes. Use it to explore layout or navigation if you have access. Evaluate accessibility, integration and deployment separately before using a prototype as a production website. Check feature and plan availability in your own account before committing to the workflow.
