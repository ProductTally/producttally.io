How to export Gamma to PowerPoint with editable tables

Build a five-slide proposal in Gamma, export it to PPTX, and check the budget table, layout and Free-plan badge in PowerPoint.

By Evan · Updated Nov 11, 2026

On this page

  1. Quick answer
  2. Start with a brief you can check
  3. Generate the deck and review the commitments
  4. Export as PPTX with editable tables enabled
  5. Check the exported file in PowerPoint

Quick answer

In Gamma, open Share → Export, leave Editable tables enabled, and select Export to PowerPoint. Open the PPTX before sending it. Gamma’s Free plan adds a badge, and generated copy can introduce terms you never supplied.

Gamma Review

Start with a brief you can check

We used Gamma 5 Agent on the Free web plan on November 11, 2026, with a Chinese interface and an English brief. The fictional newsletter pilot covered five slides: cover, goal, scope, budget and next steps. Give Gamma the exact amounts and request a real table: $300 setup, three issues at $350 each, and a $1,350 total.

Generate the deck and review the commitments

Review the outline, generate the slides and compare them against the original brief. The budget figures survived in our sample. Gamma added reporting and an invoicing condition that the brief did not specify. We manually changed a text label in Gamma and saw the change in the export. Remove any unapproved terms before sharing a real proposal.

Export as PPTX with editable tables enabled

Open Share → Export, choose all slides, leave the quality at Standard and keep Editable tables enabled. Select Export to PowerPoint. We also left Scale to fit enabled. Gamma says embedded web content and some visual effects may change or drop out in PowerPoint. Export a PDF as a reference if exact appearance matters.

Check the exported file in PowerPoint

The macOS PowerPoint app opened all five slides. On slide four, the budget displayed the three columns, the $1,350 total and a Gamma badge in the lower-right corner. The PPTX contained a native table, but the local PowerPoint installation required activation to edit and save. In an activated editor, change one cell and one title, save a copy, and check that the other amounts, fonts and line breaks still look right.
