How to check PDF citations in NotebookLM (Gemini Notebook)

Quick answer

Create a notebook from several PDFs, compare conflicting details and verify the citations before sharing a brief.

Gemini Notebook Review

Start with sources you can check

Create a notebook and add two or three PDFs you have permission to use. Keep the title and date visible so you can tell versions apart. Select the documents you want the chat to use.

Ask for a comparison

Ask for a table with one row per source and columns for publication date, the figure or policy, and its citation. Ask the notebook to identify disagreements and report missing information.

Open each citation before sharing

Read the cited passage and check the unit, date and scope against the original document. If a citation opens a whole document, locate the passage yourself. Keep unresolved discrepancies in the brief.

Explore Google’s public example

Google’s May 2026 I/O notebook uses blog posts, keynote videos and demos as sources. Google demonstrates asking questions about the launches and provides an Audio Overview and a slide deck. The example shows the workflow on Google’s own sources.
