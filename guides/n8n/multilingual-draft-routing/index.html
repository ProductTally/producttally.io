How to filter and route multilingual drafts in n8n

Run a three-record editorial queue in n8n and see which articles pass the ready check.

By Evan · Updated Nov 11, 2026

On this page

  1. Quick answer
  2. Import the sample and run it manually
  3. Check the status rule and the output
  4. Retest before connecting your own queue

Quick answer

In our local n8n 2.46.7 run on November 11, 2026, the workflow received three sample records. The English and Simplified Chinese records were ready and passed. The Spanish draft was excluded.

Download the sample n8n workflow (JSON)

n8n Review

Import the sample and run it manually

Download the JSON and choose Import from File in the n8n workflow menu. Open the imported workflow and run it manually. The sample uses a Manual Trigger and two Code nodes with fictional records. It requires no connected accounts.

Check the status rule and the output

The first Code node creates three records with lang, title and status. The second keeps records with status exactly equal to ready, then uses lang to produce a sample path. Inspect its output. You should see en and zh-CN and no Spanish draft.

Retest before connecting your own queue

Change the Spanish record from draft to ready and run again. Expect three outputs. The generated paths are sample strings. Set an explicit language-to-path map for your own site and keep the output as a review queue until you have verified it.
