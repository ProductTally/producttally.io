What is Oh Dear for? Monitoring public websites and critical links

Decide when homepage uptime is enough and when you need path, certificate and broken-link checks.

By Evan · Updated Nov 16, 2026

On this page

  1. Quick answer
  2. Pick a check for the failure you care about
  3. Know what a successful HTTP response proves
  4. Set a scope one person can respond to
  5. Choose a plan after one alert reaches its owner

Quick answer

Oh Dear suits small publishers who need to catch page failures, expiring certificates and broken links from outside their website. If you only need to know when a single homepage is unreachable, a basic uptime alert may be enough. Add checks when failure on a specific path would affect readers or sales.

Oh Dear Review

Pick a check for the failure you care about

Suppose a guide and the homepage both work, but the linked workbook was deleted. A separate check on the workbook URL monitors that known address. A crawl can discover the broken link from the guide if the link is exposed in reachable HTML. A certificate check answers a different question: can people open the relevant HTTPS host without a certificate warning?

Know what a successful HTTP response proves

A download page can return 200 while showing a generic placeholder. Oh Dear documents a response-text expectation for a stable marker. If a customer needs to log in and then pay, test that full sequence separately. A Laravel community report also distinguishes outside availability checks from application diagnostics.

Set a scope one person can respond to

Start with the homepage and the two pages readers rely on most, such as the guide index and a download. Record who will respond, the exact URL and a known-good result. Use the companion 404 guide to see how the trial separated the healthy homepage, a failing path and a later check on a different target.

Choose a plan after one alert reaches its owner

Compare plan limits with the sites you need and check how extra monitored addresses count. Verify the alert channel during the trial and inspect one report yourself. Our test delivered a broken-link email, and covered one publisher’s site. It did not measure reliability over time.
