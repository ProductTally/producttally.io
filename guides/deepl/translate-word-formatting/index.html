DeepL Translator: How to translate a Word document with DeepL and check the formatting

Translate a DOCX with DeepL, then compare headings, tables, links and product terms with the original.

By Evan · Updated Nov 11, 2026

On this page

  1. Quick answer
  2. Make a one-page test document
  3. Translate and check the plan
  4. Compare the output with the source

Quick answer

DeepL says translated files from a free account are not editable. Check page breaks, links and terms before publishing.

DeepL Translator Review

Make a one-page test document

Create a DOCX with a heading, a two-column Features and Limits table, and a hyperlink labeled Read the setup guide. Repeat one product term, such as workspace, in a heading and a table cell. Use sample content you can share with the service.

Translate and check the plan

Sign in to the web translator, open Translate files, upload the DOCX and choose one target language. On a plan that supports file glossaries for that language pair, set the approved translation of workspace before starting. DeepL documents a 5 MB and 100,000-character limit per Word file for free accounts. Free output cannot be edited.

Compare the output with the source

Open both files side by side. Check heading levels, table row and column counts, clickable link destinations, page breaks and each instance of the product term. Repeat with Simplified Chinese, Japanese or Spanish as needed. A matching table layout still needs a separate check for numbers and meaning.

What a published pilot established

In a DeepL-published customer case, a five-person Sumitomo Corporation team ran a roughly one-month trial of the interface and glossary in 2025. They proceeded to company-wide deployment and used DeepL for full PDFs and slide decks. The customer reports retaining those layouts. Their case provides evidence for that enterprise workflow, with no Word-format accuracy figures.
