How to merge a workshop handout and check its page order in PDF2Go

Put the workshop agenda before the checklist, merge the files and use the built-in viewer to check the first and last pages. Compress the finished document only if it needs to be smaller.

By Evan · Updated Nov 11, 2026

On this page

  1. Quick answer
  2. Put the pages in the order readers need
  3. Decide whether to compress the handout

Quick answer

On November 11, 2026, we used PDF2Go’s English web interface without buying a plan or starting a paid trial. We uploaded two synthetic one-page PDFs with distinct labels, A and B. The viewer confirmed the merged order was B, then A. We also compressed the image-heavy sample B separately. PDF2Go reported a reduction of about 82%, from 1.2 MB to 217 KB.

PDF2Go Review

Put the pages in the order readers need

Open Merge PDF and upload the files. For a workshop, put the agenda first and the checklist last. In our test, B represented the first page and A the second, so Name (Z–A) put them in the intended order.

Give the output a descriptive name and select Merge. When processing finishes, open More actions → View on the output row.

Check the page count, then read the first and last pages. Our two-page preview showed B first and A second, with their headings and markers legible. For a longer handout, check where each source file begins as well.

Decide whether to compress the handout

In a separate test, we uploaded sample B to Compress PDF, chose Strong Compression, and selected Start. PDF2Go displayed 217 KB and approximately 82% smaller. Its viewer still showed the original heading, marker and textured image. That result describes one synthetic input. For a real handout, compare the original and compressed version at the size readers will use, especially diagrams and small type.

Chrome blocked the merged file’s download in the test profile. We verified the page order and legibility in PDF2Go’s viewer. We did not verify either output in a local PDF reader or at print size. Before distributing a handout, download the finished copy in your environment and open it locally.
