How to test a Sked Social client approval link before scheduling

Use two versions of one draft to verify client access, requested changes and final sign-off.

By Evan · Updated Nov 16, 2026

On this page

  1. Quick answer
  2. Prepare one post and define what approval covers
  3. Open the review link as the client
  4. Record the version you actually schedule

Quick answer

Sked Social can give a client a review link for selected social accounts. Before using it, confirm what a signed-out reviewer can see and make sure the approval belongs to the exact version you plan to schedule. On November 11 we reached the trial dashboard. The following steps come from the official approval guide.

Sked Social Review

Prepare one post and define what approval covers

Use a fictional workshop announcement. Version 1 has a caption, image and proposed publication time. Have an internal reviewer check the account, dates, link and crop. Keep internal discussion in Internal Comments. For instructions the client needs to see, use external notes only after checking their visibility.

Open the review link as the client

Create a review link for the intended accounts and check the configured statuses and reviewer permissions. Open it in a signed-out window on desktop and phone. Check that the test draft appears, unrelated accounts are absent, and private comments stay hidden. Use Request changes to ask for a new registration deadline. Then confirm that feedback is visible to the team.

Record the version you actually schedule

Update the deadline in Version 2 and check the updated preview from the reviewer’s view. Ask the test reviewer to approve Version 2. Confirm the result in Sked, then check time zone, account and schedule. If the preview still shows Version 1 or the approval cannot be tied to Version 2, hold the post. The exercise proposes acceptance checks; client actions and live posting were not observed.
