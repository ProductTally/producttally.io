How to preview a Social Intents chat widget before adding it to your site

Check the greeting, test a sample question and compare the visitor and agent views.

By Evan · Updated Nov 11, 2026

On this page

  1. Quick answer
  2. Set up a clear first message
  3. Compare the visitor and agent views

Quick answer

Social Intents documents a widget preview and a separate test playground. We reached the dashboard on November 11, 2026. This guide follows the official setup procedure. Agent replies and live widget delivery were outside the observed workflow.

Social Intents Review

Set up a clear first message

In Chat Widgets, choose a test widget and give it the name visitors should see. Write a greeting that explains which questions the team handles. Open Preview and check that the greeting and launcher fit on a narrow screen.

Compare the visitor and agent views

Use a fictional customer question such as “Where can I find the workshop schedule?” Check how it appears in the selected agent interface and review the offline message. Use a test page before adding the widget to a live site. Compare plans by widgets and seats.
