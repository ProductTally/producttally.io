How to test a Social Intents chat widget before launch

Check the mobile launcher, an agent reply and the offline experience before adding chat to your live site.

By Evan · Updated Nov 16, 2026

On this page

  1. Quick answer
  2. Preview the widget where it could get in the way
  3. Send a message you can recognize in both views
  4. Repeat when nobody is available

Quick answer

Use Social Intents Preview to check appearance, then install the widget on your staging page to check whether a message reaches an agent and their reply comes back. On November 11 we reached the dashboard. The walkthrough below follows the vendor’s instructions; two-way chat and offline delivery were not tested.

Social Intents Review

Preview the widget where it could get in the way

For a workshop page, use a greeting that says what the team can answer. In Preview, open and close the launcher on desktop and on a narrow screen. Check that it does not cover the registration button. Preview on the actual test page too, since a floating button can overlap the page differently.

Send a message you can recognize in both views

Open your staging page with the widget installed. As the visitor, ask “Where is the workshop schedule?” and add a short test label. In the inbox or supported team channel you actually intend to use, check which widget or queue received it, then reply with the schedule link. Return to the visitor window and open the link. Record whether each direction worked separately.

Repeat when nobody is available

Use a test window when the widget is set to offline or outside the configured hours. Check what the visitor is offered, then submit a message only if a contact form appears. Verify where it arrives and what the visitor is told. If the team never receives it, fix that route before installing the widget. This is a proposed acceptance test; our session did not send a live chat or offline message.
