SEOPress Free: set a WordPress SEO title and verify noindex on one page

Check the saved HTML and page sitemap before and after excluding a utility page.

By Evan · Updated Nov 16, 2026

On this page

  1. Quick answer
  2. Set a search title and check the rendered HTML
  3. Check noindex and sitemap membership separately
  4. Recheck when a page should return to search

Quick answer

On November 11, 2026, SEOPress Free 10.4 on local WordPress 7.1.4 kept our custom title and rendered a robots meta tag with follow, noindex after we excluded one page. The page also disappeared from the generated page sitemap. Check both outputs after changing a page that you want accessible by link but absent from search.

SEOPress Review

Set a search title and check the rendered HTML

We used a sample page headed “Workshop checklist QA” and set its SEO title to “Workshop checklist for solo creators | QA” in the Titles settings of the SEOPress panel. After saving, open the public page as a visitor and choose View Page Source. Search for the title element to confirm the saved value. Our visible heading kept its original wording.

Check noindex and sitemap membership separately

For a utility page you want excluded, enable the page-level noindex option under Advanced and save. Reload the visitor page and find the robots meta tag. Our saved value was follow, noindex. Then open the page sitemap from its index and search for the page URL. The test URL disappeared, while the other sample page stayed. If output looks stale, check the public cache and any conflicting robots directive in the response headers.

Recheck when a page should return to search

Clear the page-level setting, refresh or purge any cache and verify that neither the HTML nor the X-Robots-Tag response header still contains noindex. If the page should be in the sitemap, confirm that its canonical URL is listed. Google must be able to crawl the URL to see noindex or its removal. A search engine’s actual index was outside this local test.
