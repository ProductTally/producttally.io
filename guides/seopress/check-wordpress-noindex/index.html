Set a WordPress page’s SEO title and check noindex with SEOPress Free

Use SEOPress Free to save a title and description for an individual page, then inspect the HTML and XML sitemap. For a utility page you intend to keep out of search, repeat the checks after enabling noindex.

By Evan · Updated Nov 11, 2026

On this page

  1. Quick answer
  2. Save the SEO title and description
  3. Check the page sitemap before and after noindex

Quick answer

On November 11, 2026, we ran this workflow on a temporary local WordPress Playground site using WordPress 7.1.4, PHP 8.3 and SEOPress Free 10.4. The editor was in English, and the page contained synthetic test copy.

SEOPress Review

Save the SEO title and description

In the WordPress page editor, open the SEOPress toolbar control and choose Titles & Metas. Enter a title that describes what the page offers, then add a short, specific description. Save the SEO settings and the page.

Open the rendered page and view its HTML source. Search for <title> and name="description" and compare the values with what you saved. Find the rel="canonical" link and check its destination. In our test the canonical pointed to the page’s own URL.

Compare the browser title with the visible heading. Our SEO title was “Workshop checklist for solo creators | QA.” The page’s H1 stayed “Workshop checklist QA.” The SEOPress preview can help you check the text while editing. The HTML source shows what the page actually sends.

Check the page sitemap before and after noindex

With XML sitemaps enabled in SEO → XML–HTML Sitemap, open the sitemap index and follow the link to the page sitemap. On our local site that file was page-sitemap1.xml. Search it for the page URL and confirm it appears.

Reopen a utility page you deliberately want to exclude from search. In the SEOPress Advanced panel, enable the page-level noindex checkbox and save.

Reload the page source and check the robots meta tag. Our test page emitted follow, noindex and retained its custom title and description. Reload the page sitemap. The test URL had disappeared, and the default sample page was still listed.

The test covered local HTML and XML output. Live crawling, indexing, ranking, migration and PRO features were outside its scope. For Google to process a live page’s noindex directive, Googlebot needs access to the page.
