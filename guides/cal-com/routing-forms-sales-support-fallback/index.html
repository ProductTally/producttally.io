Cal.com Routing Forms: separate sales from support before booking

Build one intake form for demos, customer support and general inquiries. Test the rule that keeps a large customer’s support request out of the sales calendar.

By Evan · Updated Nov 16, 2026

On this page

Quick answer

Cal.com Routing Forms is useful when visitors share one entry point but need different destinations. Cal.com lists basic routing under Teams. Start with a support rule, then qualifying demo rules, then a fallback. If everyone should see the same calendar, a shared booking link is simpler.

Cal.com Review

Prepare the destinations before writing rules

Imagine a two-person software studio with a general demo calendar, a separate calendar for larger accounts, and a support page. Keep a short contact page for anything the form cannot classify. Ask for the visitor’s purpose (demo, support or other) and, for demos, their team size. Use 50 people as this studio’s example cutoff. This cutoff is specific to the example studio.

Put the exception above the general demo rule

Rule 1: support → support page, regardless of company size. Rule 2: demo and 50 or more people → larger-account calendar. Rule 3: any other demo → general demo calendar. Fallback: anything else → contact page with a next step. Cal.com says it checks routes in order. A 50-person demo qualifies for both demo rules, so the larger-account rule must come first.

Use four submissions as a release check

Expected destinations: A, support at 80 people → support page. B, demo at exactly 50 → larger-account calendar. C, demo at 49 → general calendar. D, other → fallback. These are expected outcomes for the sample rules. Submit each in a signed-out browser and save the URL or page title that actually opened. Repeat after publishing the embed, since the preview only checks the form.

Confirm host assignment separately

A correct route only proves the visitor reached the right destination. If the sales calendar uses Round Robin, make a test booking and check the confirmation for the assigned host. The Teams pricing page lists basic routing. Confirm the plan separately if you need member attributes such as region or language to decide who can take a booking.
