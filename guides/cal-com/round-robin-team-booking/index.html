How to set up Cal.com round robin for a two-person team

Use one team booking link and test who gets assigned when both hosts, one host or neither host is free.

By Evan · Updated Nov 13, 2026

On this page

  1. Quick answer
  2. Set up a meeting with one host
  3. Check three time slots
  4. Check rescheduling and handoff

Quick answer

Use a Cal.com round-robin event when a guest needs to meet any one of your hosts. Use a collective event when all selected hosts must attend. Test with two calendars before sharing the link, and check which team plan provides the scheduling controls you need.

Cal.com Review

Set up a meeting with one host

Create a team event and select Round Robin. For a hypothetical 30-minute discovery call, add Ana and Luis, check that each has the correct availability and conflict calendar, select Maximize availability, and start without custom weights. Write down the booking owner you expect in each test case. Review the current plan comparison if you also need fixed distribution or additional routing.

Check three time slots

Set up one slot where both hosts are free, one where only Ana is free and one where both are busy. From a guest session, confirm the first two slots appear, book separate tests, and check the host name on each confirmation. The second slot should assign Ana. The busy slot should be unavailable. With both available, the scheduling settings determine who receives the booking, so a single booking cannot establish equal distribution.

Check rescheduling and handoff

Reschedule one sample booking and confirm whether it keeps its host under the chosen settings. If your team requires both people on the call, create a collective event and rerun the calendar checks. Share the team link once the guest confirmation and host calendar agree.
