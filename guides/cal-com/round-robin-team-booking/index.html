Test Cal.com round robin with two hosts and three booking slots

Check which times appear, who receives each appointment and when to use load balancing.

By Evan · Updated Nov 16, 2026

On this page

  1. Quick answer
  2. Set up predictable calendars
  3. Log the result at each checkpoint
  4. Choose what you want to optimize

Quick answer

Use Cal.com Round Robin when a guest can meet either host. Choose Maximize availability if you want every eligible time to appear. In the test below, the slot with only Ana free should go to Ana, the slot with nobody free should disappear, and the shared slot should assign exactly one host.

Download the three-slot booking checklist

Cal.com Review

Set up predictable calendars

Create one 30-minute team event. Add Ana and Luis, check their conflict calendars, and turn on Maximize availability. Run the exercise in one time zone, with no buffers or lead-time restrictions interfering with these slots. Use one date far enough ahead to book and reserve 10:30 for Luis on his conflict calendar. Block 11:00 for both. Leave 10:00 free for both.

Log the result at each checkpoint

At 10:00, the link should offer a slot; record which of the two hosts gets the test booking. At 10:30, the link should offer a slot and the invite should name Ana. At 11:00, the link should offer no slot. Compare the guest invite with the assigned host calendar and note the result in the CSV. If Ana is free but 10:30 is missing, first check her event availability, conflict calendars, buffers and booking notice.

Choose what you want to optimize

Load balancing is for teams that want to share work more evenly. Cal.com says it can withhold availability from a host who has received too many bookings. Test a run of comparable bookings before judging the distribution. If Ana and Luis must attend together, use Collective and expect only the shared 10:00 slot. These are documented rules and a proposed team test; our prior Cal.com check covered an individual booking preview.
