Dropbox presenta DBX Agent Cloud: dónde encaja el almacenamiento de Tigris

Dropbox incorpora acciones de IA a su espacio de archivos, mientras DBX Agent Cloud empieza con almacenamiento de objetos compatible con S3 para desarrolladores.

Por Evan · Publicado 19 nov 2026 · Actualizado 19 nov 2026

El anuncio de Dropbox de noviembre de 2026 describe dos productos relacionados, pero distintos: un espacio de Dropbox con asistencia de IA para equipos que trabajan con sus archivos actuales y DBX Agent Cloud, una capa de almacenamiento y datos para empresas que crean aplicaciones de IA. Dropbox afirma que completó la adquisición de Tigris el 17 de noviembre. El espacio de archivos de Dropbox es SaaS; Tigris se describe mejor como un servicio gestionado de almacenamiento de objetos en la nube para desarrolladores. Ambos se ofrecen en línea, pero resuelven tareas diferentes.

Una empresa, dos trabajos de producto

La nueva experiencia de Dropbox añade búsqueda y acciones de IA al espacio conocido de almacenamiento y colaboración. DBX Agent Cloud sigue otra dirección, centrada en infraestructura: Dropbox dice que empieza con almacenamiento de objetos independiente que se puede contratar por separado y usar con los proveedores de nube y cómputo elegidos. La adquisición de Tigris corresponde a esa línea para desarrolladores; no cambia el propósito de las carpetas cotidianas de Dropbox.

Qué pueden hacer los equipos en la nueva experiencia de Dropbox

Dropbox afirma que las personas pueden preguntar sobre archivos, resumir carpetas, comparar versiones, redactar documentos, editar PDF e imágenes, transcribir grabaciones y organizar o renombrar archivos. Antes de realizar cambios compatibles, Dropbox muestra un plan para aprobar; las acciones respetan los permisos existentes y se pueden revisar o deshacer.

La disponibilidad importa: según la actualización de Dropbox del 17 de noviembre, el despliegue inicial se dirige a equipos Standard y Advanced elegibles de Estados Unidos, Reino Unido y Australia, primero en inglés. Dropbox dice que más de 70.000 equipos ya lo han recibido y prevé ampliar el acceso en 2027. Su guía para administradores indica que la experiencia de IA está incluida en Standard y Advanced, mientras que las consultas de chat y las acciones de IA consumen créditos del equipo. Comprueba el acceso y los créditos restantes antes de organizar un flujo compartido.

Dónde encaja Tigris para desarrolladores

Tigris presenta su producto como almacenamiento de objetos compatible con S3 para aplicaciones que funcionan en varios proveedores de nube y cómputo. Los desarrolladores pueden conectarse con SDK habituales de AWS y herramientas como AWS CLI o boto3. Dropbox describe DBX Agent Cloud como un servicio que comienza con almacenamiento de objetos independiente; las capacidades de sistema de archivos y procesamiento de contenido están previstas para después, no deben darse por disponibles hoy.

Tigris interesa a equipos que crean una aplicación o agente y necesitan conservar archivos, conjuntos de datos o medios generados. Es un servicio de nube gestionado, pero su categoría es almacenamiento de infraestructura para desarrolladores, no un SaaS general de gestión de trabajo para creadores.

¿Qué producto debería evaluar un equipo pequeño?

Si el trabajo del equipo ya está en Dropbox, comprueba primero si la nueva experiencia está habilitada, qué plan corresponde y cómo se comparten los créditos de IA. Empieza con una carpeta de bajo riesgo y revisa las acciones propuestas antes de aprobarlas.

Si estás desarrollando una aplicación de IA, compara Tigris o DBX Agent Cloud con tus necesidades de almacenamiento: compatibilidad con la API de S3, ubicación del cómputo, controles de acceso, precios actuales y funciones disponibles hoy. No decidas solo por una hoja de ruta anunciada. La diferencia práctica: el espacio de Dropbox ayuda a las personas a trabajar con archivos; Tigris aporta almacenamiento de objetos que los desarrolladores integran en software.
