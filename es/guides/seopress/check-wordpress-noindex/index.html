SEOPress Free: configura el título SEO y verifica noindex en WordPress

Comprueba el código fuente y el sitemap de páginas antes y después de excluir una página auxiliar.

Por Evan · Actualizado 16 nov 2026

En esta página

  1. Respuesta rápida
  2. Configura el título y abre el código fuente
  3. Comprueba por separado robots y el sitemap
  4. Vuelve a comprobar si la página debe aparecer en búsquedas

Respuesta rápida

El 11 de noviembre de 2026, en WordPress 7.1.4 local con SEOPress Free 10.4, se mantuvo el título personalizado y la etiqueta robots pasó a follow, noindex después de excluir una página. La URL dejó de aparecer en el sitemap de páginas. Comprueba ambos resultados si quieres que una página siga disponible por enlace sin aparecer en las búsquedas.

Reseña de SEOPress

Configura el título y abre el código fuente

En la página de prueba titulada “Workshop checklist QA”, pusimos “Workshop checklist for solo creators | QA” como título SEO en el panel de SEOPress. Guarda, abre la página como visitante y elige Ver código fuente. Busca el elemento title y compara el valor guardado. En la prueba el encabezado visible conservó el texto original.

Comprueba por separado robots y el sitemap

Para excluir una página auxiliar, activa noindex en los ajustes avanzados de esa página y guarda. Carga la página de nuevo y busca la etiqueta meta robots. En la prueba indicó follow, noindex. Abre el sitemap de páginas desde su índice y busca la URL. La página de prueba desapareció y la de ejemplo siguió allí. Si todavía ves la versión anterior, revisa la caché y las directivas de las cabeceras HTTP.

Vuelve a comprobar si la página debe aparecer en búsquedas

Desactiva noindex y actualiza o vacía la caché. Comprueba que noindex ya no esté en el código fuente ni en la cabecera X-Robots-Tag. Si la página debe figurar en el sitemap, busca su URL canónica. Google necesita poder rastrearla para ver la directiva o su retirada. La prueba local no midió la indexación real.
