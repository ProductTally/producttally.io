Cómo hacer una redirección 301 con SEOPress PRO al cambiar una URL de WordPress

Asocia la URL antigua con la nueva y comprueba el estado HTTP, los enlaces internos y el sitemap.

Por Evan · Actualizado 13 nov 2026

En esta página

  1. Respuesta rápida
  2. Configura las dos direcciones
  3. Comprueba la respuesta inicial y la página final
  4. Actualiza los enlaces que controlas

Respuesta rápida

Si un artículo se mueve de forma permanente, configura una redirección 301 en SEOPress PRO. Indica la ruta relativa antigua y la URL HTTPS completa de destino. La primera debe devolver 301 y llevar directamente a la nueva, que debe responder con 200.

Reseña de SEOPress

Configura las dos direcciones

En este ejemplo, /guides/old-post/ pasa a https://example.com/guides/new-post/. Comprueba que la página nueva esté publicada. En WordPress activa las redirecciones en SEO → PRO → Redirections / 404 y añade una regla desde SEO → Redirections. Usa guides/old-post como origen, la URL completa como destino, el tipo 301 y la condición de acceso All. Guarda la regla habilitada. Usa una regla concreta para este artículo.

Comprueba la respuesta inicial y la página final

Abre la URL antigua sin iniciar sesión o ejecuta curl -sS -o /dev/null -D - https://example.com/guides/old-post/. Comprueba el 301 y que Location apunte a la nueva URL. Solicita el destino por separado y comprueba que devuelve 200. Si hay un salto intermedio, revisa las demás reglas, la normalización de WordPress y el CDN. Si interviene la caché, vacía la que corresponda y repite.

Actualiza los enlaces que controlas

Cambia los enlaces internos y revisa la etiqueta canonical. Si el artículo puede indexarse, verifica que el sitemap incluya la URL nueva. Si usas parámetros de campañas, prueba una consulta de ejemplo y comprueba qué parámetros llegan. Mantén la redirección para los enlaces antiguos y reserva este destino para contenido realmente equivalente.
