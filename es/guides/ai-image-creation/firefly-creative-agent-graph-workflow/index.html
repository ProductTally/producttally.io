Adobe Firefly Creative Agent y Firefly Graph: un flujo para equipos pequeños

Parte de una foto de producto para elegir entre Quick Actions, Plan Mode y Graph, con un ejercicio y la disponibilidad anunciada en Adobe MAX 2026.

Por Evan · Actualizado 11 nov 2026

Respuesta rápida

Usa Quick Actions para una edición puntual compatible, Plan Mode de Firefly AI Assistant para revisar una secuencia y Firefly Graph para probar un flujo repetible. Adobe indica que AI Assistant y Graph están en beta y Builder en beta privada con lista de espera. La guía se basa en el anuncio del 10 de noviembre; el ejercicio es una propuesta.

Una foto, dos entregables

Elige una foto que puedas usar y guarda el original. Prepara una imagen cuadrada y otra vertical, conservando el color y la forma del producto. Pide un fondo limpio y espacio para el titular, sin añadir texto ni logotipos.

Elige el camino más simple

Para cambiar la iluminación, prueba la acción correspondiente. Adobe indica que Edit Text, Retouch, Relight y Quick Actions ya están disponibles de forma general. Si tienes Plan Mode, revisa la secuencia de AI Assistant antes de generar e indica qué pasos requieren aprobación.

Prepara un Graph reutilizable

Si tienes acceso a Graph, define cuatro etapas: foto original, fondo, versiones cuadrada y vertical, y revisión humana. Usa la foto y las proporciones como entradas. Repite con otra foto y apunta modelo, reintentos y correcciones manuales.

Comprueba los archivos exportados

Compara los bordes, el color, la etiqueta y el recorte con el original a tamaño real. Previsualiza cada formato en su destino. Registra tiempo y créditos visibles, compáralos con tu editor habitual y decide si merece la pena repetir el flujo.

Evalúa Builder por separado

Adobe presenta Builder como una beta privada para prototipos interactivos. Si tienes acceso, úsalo para explorar diseño y navegación. Antes de lanzar el sitio, comprueba accesibilidad, integración y despliegue. Confirma en tu cuenta las funciones y el plan disponibles.
