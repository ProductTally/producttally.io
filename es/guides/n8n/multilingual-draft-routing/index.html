Cómo filtrar borradores multilingües y enviarlos a revisión con n8n

Ejecuta una cola editorial de tres registros y comprueba cuáles pasan el filtro de estado.

Por Evan · Actualizado 11 nov 2026

  2. Importa y ejecuta el ejemplo manualmente

Respuesta rápida

El 11 de noviembre de 2026 ejecutamos tres registros de ejemplo en n8n 2.46.7 en local. Los registros en inglés y chino simplificado pasaron con el estado ready. El borrador en español quedó fuera.

Descargar el flujo de ejemplo para n8n (JSON)

Reseña de n8n

Importa y ejecuta el ejemplo manualmente

Descarga el JSON y elige Import from File en el menú del flujo. Abre el flujo y ejecútalo manualmente. Usa un disparador manual y dos nodos Code con datos ficticios. No requiere cuentas conectadas.

Comprueba el filtro y el resultado

El primer nodo Code genera tres registros con lang, title y status. El segundo conserva los que tienen exactamente el estado ready y usa lang para generar una ruta de ejemplo. En la salida deben aparecer en y zh-CN, sin el borrador en español.

Vuelve a probar antes de conectar tu cola

Cambia el estado del registro en español de draft a ready y vuelve a ejecutar el flujo. Debes obtener tres resultados. Las rutas generadas son ejemplos. Define qué ruta real corresponde a cada idioma y revisa la salida antes de conectar otro paso.
