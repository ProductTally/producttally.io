AdGuard Ad Blocker: Extensión de AdGuard o aplicación de escritorio: cuál encaja con tu trabajo

Compara la cobertura del navegador y del equipo. Comprueba inicios de sesión, vídeos y formularios.

Respuesta rápida

Empieza con la extensión gratuita si solo necesitas filtrar un navegador compatible. Valora AdGuard para Windows o Mac si necesitas filtrar otros navegadores o aplicaciones de escritorio compatibles. La cobertura depende del sistema y de la configuración. Browser Assistant complementa la aplicación de escritorio.

Reseña de AdGuard Ad Blocker

Prueba tres tareas habituales

Usa un perfil separado con los filtros predeterminados. Compara una página de lectura, un inicio de sesión y un vídeo o formulario con el filtro activado y desactivado. Mantén los demás ajustes y anota si consigues completar cada tarea.

Identifica qué añade la aplicación

Anota qué aplicación o segundo navegador quieres cubrir. La extensión filtra el navegador donde está instalada. La aplicación puede filtrar tráfico compatible fuera del navegador, según tus ajustes. Sigue la guía de compatibilidad de AdGuard y usa Browser Assistant si quieres controlar la aplicación desde el navegador.

Limita las excepciones al sitio necesario

Si una página de trabajo de confianza falla, prueba una excepción solo para ese sitio y vuelve a realizar la tarea. Restablece el filtrado si la excepción deja de ser necesaria. Antes de comprar, verifica cuántos dispositivos cubre la licencia, el periodo de cobro y el precio de tu región.
