Automatización de flujos de trabajo

n8n

n8n conecta datos y herramientas en flujos visuales. Un equipo pequeño puede convertir reglas repetibles, como enviar borradores a revisión, en pasos que se pueden inspeccionar y probar.

Por Evan · Comprobado 11 nov 2026

n8n · Visitar la web oficial Guardar producto n8n Ver las guías de este producto

Funciones del producto

  • Crea flujos con nodos visuales y usa un nodo Code para filtrar y transformar datos en un solo paso.
  • El autoalojamiento requiere mantener la instancia. Los planes alojados se cobran por ejecuciones.

Por qué elegirlo

  • Para equipos que aplican las mismas comprobaciones a los registros entrantes.

Cómo empezar

  1. Descarga el JSON y elige Import from File en el menú del flujo. Abre el flujo y ejecútalo manualmente. Usa un disparador manual y dos nodos Code con datos ficticios. No requiere cuentas conectadas.
  2. El primer nodo Code genera tres registros con lang, title y status. El segundo conserva los que tienen exactamente el estado ready y usa lang para generar una ruta de ejemplo. En la salida deben aparecer en y zh-CN, sin el borrador en español.
  3. Cambia el estado del registro en español de draft a ready y vuelve a ejecutar el flujo. Debes obtener tres resultados. Las rutas generadas son ejemplos. Define qué ruta real corresponde a cada idioma y revisa la salida antes de conectar otro paso.
