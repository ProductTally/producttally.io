Cómo impedir que un reintento del formulario cree dos filas en n8n

Usa un ID estable y una inserción parametrizada para que un reintento del webhook no cree otro registro.

Por Evan · Actualizado 18 nov 2026

Configura el servicio de formularios para reutilizar el ID original cuando repita un envío y usa ese ID como clave única en PostgreSQL. Si el remitente agota el tiempo de espera, el webhook puede llegar dos veces, incluso si la primera escritura ya se completó. Ejecuta la inserción parametrizada con el nodo Postgres de n8n.

Deja que la base decida si hay una fila nueva

  • Nodo Postgres de n8n
  • Referencia de INSERT en PostgreSQL

En una tabla de prueba, define submission_id como clave primaria de texto. Pasa el ID y el nombre en Query Parameters, en el orden de $1 y $2. Si varias fuentes pueden asignar el mismo ID, combina el origen y el identificador en la clave. Un mismo correo puede corresponder a dos solicitudes válidas. Si falta el ID, deriva la solicitud a una rama de rechazo antes de escribir.

WITH inserted AS (
  INSERT INTO form_entries (submission_id, submission_name)
  VALUES ($1, $2)
  ON CONFLICT (submission_id) DO NOTHING
  RETURNING submission_id
)
SELECT EXISTS (SELECT 1 FROM inserted) AS created;

La primera inserción devuelve created = true. Una repetición devuelve false. Si haces una consulta previa aparte, dos ejecuciones simultáneas pueden ver la tabla sin esa fila. La clave única resuelve la concurrencia al insertar.

Comprueba la tabla y el correo por separado

Envía demo-42 dos veces y demo-43 una vez. Repite con dos solicitudes duplicadas en paralelo. Deben quedar dos filas y solo una con demo-42. Prueba también un envío sin ID y, si admites varias fuentes, el mismo ID en dos orígenes.

Activa el correo de confirmación solo para una fila nueva. Aun así, el flujo podría interrumpirse entre guardar la fila y enviar el correo. Si la confirmación es imprescindible, registra el envío pendiente en la misma transacción y deja que otra tarea gestione el envío y sus reintentos. Verifica la entrega de forma independiente.
