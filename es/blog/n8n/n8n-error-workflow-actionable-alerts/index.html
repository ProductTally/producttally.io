Crea avisos de error de n8n que tu equipo pueda resolver

Resume el problema aunque no haya enlace de ejecución y deja claro quién revisa antes de reintentar.

Por Evan · Actualizado 20 nov 2026

Inicia el flujo compartido con Error Trigger y selecciónalo en Error Workflow en los ajustes de cada flujo de producción. Los ejemplos oficiales distinguen un error durante una ejecución de otro en el disparador principal. Añade el nombre del flujo y un resumen en ambos casos. Incluye la URL de ejecución solo si está disponible.

n8n · Ver detalles del producto

Incluye el contexto que cambia la respuesta

Si un recordatorio falla tras iniciarse, facilita el enlace a la ejecución guardada cuando exista. Si el problema está en el disparador, indica dónde empezar la revisión. Omite credenciales y registros de clientes en el mensaje. Los responsables pueden consultar el contexto en el espacio autorizado.

  • Error workflows

Decide cuándo reintentar

Asigna un propietario a cada aviso. Un informe interrumpido puede admitir otro intento cuando vuelva la fuente. Antes de volver a enviar un correo o procesar un cobro, comprueba si el primer intento ya produjo el efecto.
