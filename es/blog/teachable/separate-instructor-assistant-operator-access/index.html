¿Qué acceso necesita cada persona del equipo en Teachable?

Comprueba por separado edición, progreso y facturación con una cuenta de prueba por función.

Por Evan · Actualizado 17 nov 2026

Enumera qué debe hacer cada persona y abre Settings → Roles. Usa un rol integrado si se ajusta al trabajo. Si necesitas permisos personalizados, revisa primero el plan y lo que ofrece tu cuenta.

Teachable · Ver detalles del producto

La guía actual Types of User Roles dice que los roles personalizados empiezan en Growth. Custom User Roles todavía menciona Business. Consulta la página de planes y verifica los controles disponibles en Settings → Roles. La tabla indica qué permisos debes comprobar antes de dar acceso.

Usa una cuenta de prueba para cada función

Usa una cuenta de prueba por rol. Abre las páginas necesarias y prueba también los cursos o datos financieros que deberían estar restringidos. Si una tarea obliga a conceder demasiado acceso al tutor, déjala con el responsable que ya tenga ese permiso. Guarda la fecha, el rol y el resultado.
