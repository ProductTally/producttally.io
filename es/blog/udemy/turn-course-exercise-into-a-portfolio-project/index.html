¿Cómo conviertes un ejercicio de Udemy en un proyecto para tu portafolio?

Adapta una aplicación con una necesidad propia y datos ficticios. Documenta las pruebas y el permiso de reutilización.

Por Evan · Actualizado 18 nov 2026

Guarda el primer ejercicio como práctica privada. Crea otra versión con una necesidad que puedas explicar. Udemy admite cuestionarios, ejercicios de código y tareas. Comprueba cuáles ofrece tu curso.

Udemy · Ver detalles del producto

Dale a la aplicación un objetivo distinto

Convierte un gestor de tareas en una lista de seguimiento de soporte. Inventa incidencias con fecha, responsable y estado. Coloca primero las que estén abiertas y vencidas, y decide qué hacer si falta una fecha. Prepara tres casos ficticios: actualización normal, incidencia vencida y campo vacío. Escribe el resultado esperado de cada uno.

Por ejemplo, deja el caso cerrado T-101 en la lista normal, marca el abierto y vencido T-102 y solicita una fecha para priorizar T-103. Usa estos resultados esperados para explicar las reglas del proyecto.

Publica un ejemplo que otra persona pueda ejecutar

Usa tu propio código y revisa la licencia de cualquier archivo del instructor que quieras incluir. Elige imágenes y datos propios o autorizados. Deja fuera los datos reales de clientes. En el README explica el problema, las entradas, cómo ejecutar el proyecto y sus límites. Acredita el curso y describe tus aportaciones. Añade una captura real del ejemplo con el entorno y las condiciones comprobadas.
