Cómo elegir un curso de Docker Compose en Udemy

Conecta una interfaz web a PostgreSQL y comprueba con una fila si el volumen conserva los datos.

Por Evan · Actualizado 23 nov 2026

En esta página

  1. Empieza por un proyecto de dos servicios
  2. Acceso y almacenamiento local

  4. Archivo Compose para practicar

En Udemy, busca un curso de Docker Compose que te pida conectar una aplicación con la base de datos y comprobar la persistencia. Imagina que recibes un prototipo que solo funciona en el portátil de otra persona. Tu primer objetivo es que el equipo pueda levantarlo desde un archivo Compose y sepa dónde buscar cuando falla una conexión.

Udemy · Ver detalles del producto

Empieza por un proyecto de dos servicios

Para practicar en local, usa Adminer como interfaz y llama db al servicio PostgreSQL. Publica la interfaz únicamente en la dirección de bucle local, por ejemplo 127.0.0.1:8080. El servidor que indicas dentro de Adminer es db. PostgreSQL puede quedarse en la red interna de Compose sin publicar un puerto en el equipo anfitrión. Espera a que la base acepte conexiones antes de rellenar el formulario.

Acceso y almacenamiento local

PiezaConfiguraciónResultado
InterfazPuerto en 127.0.0.1Se abre en el navegador local
PostgreSQLServicio dbAdminer conecta por db
DatosVolumen con nombreSe conserva la fila

Monta un volumen con nombre en el directorio de datos de la imagen. En la imagen oficial de PostgreSQL 17, el destino es /var/lib/postgresql/data. Consulta la documentación si cambias de versión principal. Trabaja en una carpeta de prácticas independiente y con credenciales locales de prueba. Crea una tabla notes con una columna body e inserta demo entry.

Cambia el contenedor y vuelve a leer la fila

En ese proyecto, ejecuta docker compose up -d --force-recreate db y conserva el volumen. Vuelve a conectar y ejecuta SELECT body FROM notes;. La prueba de la actividad consiste en recuperar la misma fila después de reemplazar el contenedor.

El temario de *Docker Mastery* incluye comandos de Compose V2 y un ejercicio que enlaza Drupal y PostgreSQL. Empieza por esas lecciones si quieres reproducir un entorno pequeño. El ejemplo de Adminer es una práctica más corta para trabajar los mismos conceptos.

Archivo Compose para practicar

services:
  ui:
    image: adminer
    ports:
      - "127.0.0.1:8080:8080"
  db:
    image: postgres:17
    environment:
      POSTGRES_DB: practice
      POSTGRES_USER: learner
      POSTGRES_PASSWORD: ${PRACTICE_DB_PASSWORD:?Set a local practice password}
    volumes:
      - notes-data:/var/lib/postgresql/data

volumes:
  notes-data:

Define PRACTICE_DB_PASSWORD en un archivo .env local y ejecuta docker compose up -d. Visita http://127.0.0.1:8080, elige PostgreSQL e introduce db, base practice, usuario learner y tu contraseña local.
