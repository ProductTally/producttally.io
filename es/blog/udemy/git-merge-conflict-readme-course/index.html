Cómo elegir un curso de Git en Udemy para resolver conflictos

Crea un conflicto de README en un repositorio de prácticas y revisa qué cambios quedan preparados antes de confirmar.

Por Evan · Actualizado 23 nov 2026

Busca un curso que te pida leer ambos cambios y justificar el resultado.

Udemy · Ver detalles del producto

Dos ramas cambian la misma línea

En un repositorio local de prácticas, confirma un README con «Publicar el viernes». Crea dos ramas desde ese commit. En una confirma «Publicar el jueves». En la otra confirma «Publicar la edición en español el viernes». Vuelve a la primera y fusiona la segunda. El ejercicio cambia la misma línea de forma distinta para provocar un conflicto.

Consulta git status y lee las dos versiones en el archivo. Si la edición en español también se adelanta, escribe «Publicar la edición en español el jueves». Si la fecha es incierta, aclárala con la persona responsable.

  • Documentación de GitHub

Revisa lo que vas a confirmar

Elimina los marcadores del conflicto al editar el texto. Ejecuta git add README.md y git diff --cached. Verifica que se mantienen la edición y la fecha acordadas, completa con git commit y revisa el estado final. En una solicitud de cambios, explica cómo incorporaste ambas decisiones.

El curso *Git & GitHub – The Practical Guide* de Udemy incluye conflictos en VS Code, una comparación con git diff y revisión de pull requests. Si hay vista previa, busca cómo comprueba el texto después de resolver el conflicto.
