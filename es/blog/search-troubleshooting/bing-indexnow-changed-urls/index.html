¿Qué URL debes enviar a Bing IndexNow después de publicar?

Determina qué direcciones cambiaron y comprueba si Bing recibió la notificación.

Por Evan · Actualizado 19 nov 2026

Usa IndexNow para avisar a los buscadores participantes de URL concretas que se añadieron, cambiaron o retiraron. Mantén un sitemap para el descubrimiento continuo de URL canónicas. Envía el aviso cuando la página pública ya esté en su estado previsto y revisa la respuesta.

Prepara el lote a partir de los cambios del despliegue

Imagina una guía nueva, una página de precios actualizada y un anuncio retirado. Añade las dos primeras al lote. Revisa la dirección del anuncio: si hay una sustitución adecuada, configura la redirección. Si el artículo desapareció, comprueba una respuesta 404 o 410 apropiada. Incluye también esa URL antigua, ya modificada. Usa direcciones completas del host verificado.

  • Protocolo IndexNow
  • Instrucciones de Bing

Interpreta el 200 y el 202 por separado

Bing documenta la verificación del sitio mediante un archivo de clave. El protocolo indica que 200 significa envío correcto y 202 significa URL recibida, pendiente de validar la clave. Un error de host o clave puede devolver 422. El 429 indica demasiadas solicitudes. Registra la respuesta y resuelve su causa antes de volver a enviar.

  • Protocolo IndexNow
  • Instrucciones de Bing

Anota la entrega en el registro de publicación

Guarda la URL modificada, su estado público y la respuesta a IndexNow. Quita del mapa XML las URL canónicas retiradas. Bing puede descubrir cambios mediante el sitemap y consultar el nuevo estado directamente. Para saber si la URL nueva entró en el índice, compruébala en la inspección de URL.
