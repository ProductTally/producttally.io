¿A quién le envías un enlace de pCloud y a quién invitas a la carpeta?

Elige el acceso adecuado para revisar, editar y entregar archivos, y comprueba quién puede descargarlos o compartirlos.

Por Evan · Actualizado 18 nov 2026

Envía un enlace compartido si el cliente solo necesita abrir o descargar una propuesta. Puede usarlo sin una cuenta de pCloud. Si varias personas van a añadir o sustituir archivos durante el proyecto, usa Invite to folder con sus cuentas de pCloud. Para material delicado, comprueba los controles de acceso que incluye tu plan.

Con Manage también se puede compartir el acceso

Según pCloud, con View se pueden previsualizar y descargar archivos. Edit permite añadirlos, modificarlos y eliminarlos. Manage permite además volver a compartir. Los permisos de la carpeta se aplican a sus archivos y subcarpetas. Si conservas borradores internos, prepara otra carpeta para el cliente. Durante la prueba, revoca una invitación y un enlace de ejemplo. Abre ambos como destinatario y comprueba qué acceso queda.

  • Invitaciones a carpetas

Según pCloud, una invitación a una carpeta exige cuentas en la misma región, UE o EE. UU. Un enlace compartido se puede previsualizar sin cuenta. La contraseña y la caducidad personalizada son funciones Premium.

Para personas con cuentas en distintas regiones, pCloud propone un enlace compartido con cargas habilitadas para que sus usuarios puedan enviar archivos. Si solo necesitas recibir entregas, considera File Requests. Quien sube un archivo no necesita ver el contenido existente.
