DeepL Translator

DeepL Translator translates text and files such as Word documents, PDFs and presentations. It suits creators and small teams that need a multilingual draft they can review against the original.

  • Upload a DOCX and choose a target language. Eligible plans let you apply a glossary to supported language pairs.

Why choose it

  • Translate a product brief or help document without rebuilding it from pasted paragraphs.

How to get started

  1. Create a DOCX with a heading, a two-column Features and Limits table, and a hyperlink labeled Read the setup guide. Repeat one product term, such as workspace, in a heading and a table cell. Use sample content you can share with the service.
  2. Sign in to the web translator, open Translate files, upload the DOCX and choose one target language. On a plan that supports file glossaries for that language pair, set the approved translation of workspace before starting. DeepL documents a 5 MB and 100,000-character limit per Word file for free accounts. Free output cannot be edited.
  3. Open both files side by side. Check heading levels, table row and column counts, clickable link destinations, page breaks and each instance of the product term. Repeat with Simplified Chinese, Japanese or Spanish as needed. A matching table layout still needs a separate check for numbers and meaning.
