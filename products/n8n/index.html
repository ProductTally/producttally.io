Who it is for

n8n fits repeatable work where you need to check the output at each step. Start with sample draft and ready records in a manual workflow, then connect publishing tools after the filter behaves as expected.

Product highlights

Why choose it

How to get started

  1. Download the JSON and choose Import from File in the n8n workflow menu. Open the imported workflow and run it manually. The sample uses a Manual Trigger and two Code nodes with fictional records. It requires no connected accounts.
  2. The first Code node creates three records with lang, title and status. The second keeps records with status exactly equal to ready, then uses lang to produce a sample path. Inspect its output. You should see en and zh-CN and no Spanish draft.
  3. Change the Spanish record from draft to ready and run again. Expect three outputs. The generated paths are sample strings. Set an explicit language-to-path map for your own site and keep the output as a review queue until you have verified it.

Run the workflow with one draft and two ready records. Mark the draft ready and run it again to check that all three reach the queue.
