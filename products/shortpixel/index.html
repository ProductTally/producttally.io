Product highlights

  • The WordPress plugin can bulk-optimize existing Media Library images and process new uploads.
  • Choose Lossless, Glossy or Lossy compression and create WebP or AVIF versions. The plugin supports JPEG, PNG, GIF and PDF optimization.
  • The free allowance is 100 optimization credits per month. Thumbnails also use credits, so one upload can consume more than one credit.

Why choose it

  • Handle a library of existing images through one WordPress workflow rather than exporting files individually.
  • Choose Lossless when preserving image quality is the priority, or compare Glossy and Lossy settings for a different size–quality balance.
  • Use non-expiring one-time credits for a backlog, or compare a subscription for ongoing image work.

How to get started

  1. In WordPress, install and activate ShortPixel Image Optimizer. Enter your own ShortPixel API key in the plugin settings and validate it.
  2. Choose the compression mode and original-file backup settings. Optimize a small selection of photos and graphics first and inspect the results.
  3. Use Media > Bulk ShortPixel for the remaining library. Include thumbnail usage when estimating credits, and clear the site cache after optimization.

Before a bulk run, review the images, the selected compression mode, backup availability and estimated credit use in the plugin.
