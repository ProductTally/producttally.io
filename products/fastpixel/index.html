Product highlights

  • FastPixel combines page caching, HTML/CSS/JavaScript minification, Critical CSS and CDN delivery.
  • Image optimization uses ShortPixel technology, with adaptive resizing, lazy loading and automatic WebP delivery.
  • Page and JavaScript exclusions let you leave specific pages or scripts outside the optimization workflow.
  • Free Plan covers one website and up to 1,000 pageviews per month. Paid plans increase monthly pageviews and the number of websites.

Why choose it

  • Manage caching and front-end resource optimization from one WordPress plugin.
  • Serve optimized images through a CDN without exporting each image manually.
  • Use exclusions for pages and scripts that need their original behavior.

How to get started

  1. In WordPress, search for FastPixel Website Accelerator under Plugins, install it and activate it. Follow the account connection prompts.
  2. Open FastPixel settings and review the page, image and JavaScript options. Use exclusions where a page or script needs to stay unoptimized.
  3. Check the cache status. For a stale page, use Cache Now, then inspect the cached page and run a speed check after its assets are cached.
