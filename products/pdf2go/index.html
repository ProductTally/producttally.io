How to get started

  1. Choose three handouts you can upload. Add them to the merge tool and order them as readers should encounter them.
  2. Open the merged file and review the beginning and end of each source document. If you compress it, compare legibility with the uncompressed version.

Compare the final page count with the originals and inspect a dense page at normal reading size after any compression.
