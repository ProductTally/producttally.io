Who it is for

For creators and small teams that spend much of the day researching, writing, or using web apps. Start with the extension for browser-only filtering. Check the desktop app if you also want filtering in supported apps.

Product highlights

  • The free browser extension filters ads, pop-ups, and trackers in supported browsers without requiring an account.
  • The Windows and Mac apps can filter traffic from supported apps as well as browsers. Coverage depends on the platform and settings.
  • Personal covers up to three devices and Family covers up to nine. Both are available as annual or lifetime licenses.

Why choose it

  • Start with one browser to see how filtering affects the pages you use every day.
  • Turn filtering off for a site if it interferes with a login, checkout, or embedded player.

How to get started

  1. Install the official extension for your browser and start with its default filters.
  2. Open a few sites you rely on. Check navigation, video playback, and sign-in before changing more filters.
  3. If something breaks, pause filtering for that site and reload. Compare desktop coverage before buying a license.
