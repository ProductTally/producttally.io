How to get started

  1. Upload an image you can use and select Creative mode.
  2. Start with the Subtle preset, then adjust Creativity or Resemblance as needed.
  3. Compare the output against the original at the intended display size.

Start with a conservative preset and zoom in on text, faces, or logos. Reduce Creativity or increase Resemblance if important details change.
