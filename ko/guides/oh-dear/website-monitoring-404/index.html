핵심 답변

Oh Dear는 가용성과 사이트 무결성 검사를 모읍니다. 정상 홈페이지와 별도 진단 대상을 함께 두고 시작해 보세요. 2026년 11월 10일 카드 없는 10일 체험에서 의도한 404와 대상 변경 후 정상 응답을 확인했습니다. 요금제는 구매하지 않았습니다.

Oh Dear 리뷰

권한이 있는 사이트부터 추가

홈페이지를 등록하고 각 검사가 끝나기를 기다립니다. uptime, SSL, DNS 뒤에 크롤링과 Lighthouse 결과가 나왔습니다. 해당 크롤링은 URL 126개와 끊어진 링크 0개를 보고했지만 한 번의 결과이며 전체 범위 보장이 아닙니다. 홈페이지는 정상이었습니다.

알림 유형 구분

테스트 알림과 끊어진 링크 장애 메일은 도착했습니다. 별도의 uptime 중단·복구 메일은 관찰하지 못했습니다. 링크 장애 메일만으로 모든 알림의 설정과 전달을 확인했다고 볼 수는 없습니다.

404의 전체 URL 확인

별도 모니터에서 없는 경로를 지정하자 HTTP 404가 나왔지만 홈페이지는 정상이었습니다. 눈에 띄는 장애 문구는 대상을 도메인으로 줄였습니다. 사이트 전체 장애를 알리기 전에 전체 URL, 코드와 시간을 확인하세요.

복구와 검사 시차 해석

대상을 실제 /guides/로 바꿔 다시 확인하자 HTTP 200이 나왔습니다. 장애 구간은 Asia/Shanghai 17:47:50~17:48:56입니다. 대상 변경에 따른 복구이지 운영 장애를 고친 사례가 아닙니다. 각 검사는 따로 갱신되어 이전 결과가 남을 수 있습니다.

기록과 내보내기에 맥락 더하기

새 모니터의 7/30일 항목에 나온 100%는 30일 관찰을 뜻하지 않습니다. Chrome이 CSV를 ERR_BLOCKED_BY_CLIENT로 차단해 파일을 받지 못했습니다. 서버 내보내기 고장의 증거는 아닙니다. 이후 진단 모니터의 11개 검사를 껐고 홈페이지 모니터는 유지했습니다.

사이트 수에 맞는 요금제 선택

체험은 11월 20일까지입니다. 10일 확인한 월가는 Solo €15/2개 사이트, Solo Plus €29/5개, Freelance €49/10개, Studio €99/25개, Agency €149/50개이며 VAT 별도입니다. 초기 진단에 유용한 선택지지만 Cron, 공개 상태 페이지와 장기 신뢰성은 테스트하지 않았습니다.
