Nifty 콘텐츠 협업 입문: 출시 작업과 진행 단계, 브리프를 한 프로젝트에

Nifty에서 마감일, 작업 의존성, 문서를 연결하고 내보내기 결과와 무료 요금제의 범위를 확인하세요.

핵심 답변

Nifty는 콘텐츠 출시의 작업, 단계별 진행 상황, 브리프를 한 프로젝트에 모아 줍니다. 작은 출시 하나부터 시작하세요. 이 가이드는 2026년 11월 10일 단일 사용자의 14일 체험을 바탕으로 하며 유료 구독은 구매하지 않았습니다.

Nifty 리뷰

하나의 결과물을 위한 프로젝트

Blank 프로젝트에서 Tasks, Roadmap, Docs를 켜고 초안, 교정, 최종 검토를 추가합니다. 문서에는 완료 기준을 적으세요. 공식 문서의 Public은 워크스페이스 내부 접근 범위이며 인터넷 전체에 자동 공개된다는 뜻이 아닙니다.

마감일과 하위 작업은 별도로 확인

11월 13일 마감일과 하위 작업, 영어·중국어·일본어 제목이 저장됐습니다. 그러나 상위 작업을 완료한 뒤에도 하위 작업은 0/1이었습니다. 완료 전에 체크리스트를 따로 확인하세요. 다국어 입력 성공은 완전한 기본 현지화나 언어별 날짜 해석을 입증하지 않습니다.

의존성과 자동 진행 상황 연결

선행 작업이 미완료일 때 후속 작업이 잠겼고 완료하자 잠금이 해제됐습니다. 날짜가 있는 작업은 Editorial Ready 단계의 진행률을 0%에서 100%로 바꿨습니다. 기간도 11월 10~13일에서 12~13일로 달라져 자동 일정을 고정 기준선으로 볼 수는 없습니다.

문서와 내보내기 결과 확인

3개 언어 브리프는 새로고침 후에도 남았고 Markdown에 제목과 6개 문단이 보존됐습니다. CSV에는 상위 작업 3개와 마감일이 있었지만 하위 작업은 없었습니다. 완료와 의존성 변경 전에 내보낸 파일이므로 To Do 상태는 이전 시점의 기록입니다. 전체 워크스페이스 백업이나 무손실 이전을 입증하지 않습니다.

정식 작업 전에 요금제 확인

테스트는 14일 체험에서 진행했습니다. Free 화면에는 활성 프로젝트 2개, 100 MB, 작업 500개가 표시됐습니다. 체험 종료나 다운그레이드 후 내보내기는 확인되지 않았습니다. 11월 10일 기준 연간 결제의 월 환산가는 멤버당 Pro $10, Business $16이며 월 결제와 다릅니다. 통화, 세금과 조건을 확인하세요.

작은 출시부터 시작

초기 안내가 흰 화면에 멈췄지만 Google 재로그인 후 복구됐습니다. 브리프 하나, 의존성 하나, 두 내보내기 형식을 확인한 뒤 작업을 늘리세요. 콘텐츠 맥락을 연결하려는 사람에게 검토할 만합니다. 다중 사용자 권한, 장기 신뢰성과 Free의 전체 권한은 별도 평가가 필요합니다.
