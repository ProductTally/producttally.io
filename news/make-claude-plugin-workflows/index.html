The Make plugin for Claude turns a request into a scheduled workflow

By Evan · Published Nov 28, 2026 · Updated Nov 28, 2026

Vendor announcement Nov 27, 2026

Make listed its Claude plugin in the November 27, 2026 changelog. It works in Claude Chat, Cowork and Code on all Make plans. With an existing Make account, you can create, run and schedule scenarios. Start with a test form, then check what the scenario writes before setting a schedule.

Make Help: the Claude plugin and availability · Make 2026 changelog

Connect Claude to the right Make organization

Add Make from Anthropic’s Claude plugin directory and sign in to your existing Make account. Check the organization and allowed connections if you manage both personal and team projects. Your scenarios, connections and data stay in that Make organization, and the plugin follows existing account permissions.

  • Make Help: the Claude plugin and availability
  • Make’s plugin installation and scenario demo

Map one test submission into a project sheet

For example, ask Claude to build a scenario that reads new test form submissions and sends the request ID, subject and arrival time to a test project sheet. In Make, check the source, destination and field mapping. Use the request ID to check for existing rows. Run it once with one sample and confirm that exactly one row lands in the intended sheet with the right ID and time.

  • Make Help: the Claude plugin and availability
  • Make’s plugin installation and scenario demo

Review the run before setting a schedule

Find the scenario by name in Claude and review its recent runs. In Make, you can inspect the module inputs and outputs. Once the test behaves as expected, set a cadence supported by the scenario’s trigger. Make meters module actions with credits, so reading a record and writing a row can both count towards usage.
