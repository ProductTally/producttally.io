Dropbox launches DBX Agent Cloud: where Tigris object storage fits

Dropbox is adding AI actions to its file workspace while DBX Agent Cloud starts with S3-compatible object storage for developers. Here is who each product is for.

By Evan · Updated Nov 19, 2026

  2. What teams can do in the new Dropbox experience
  3. Where Tigris fits for developers
  4. Which product should a small team evaluate?

Dropbox’s November 2026 announcement describes two related but distinct products: an AI-assisted Dropbox workspace for teams working with existing files, and DBX Agent Cloud, a storage and data layer for companies building AI applications. Dropbox says it completed its Tigris acquisition on November 17. Dropbox’s file workspace is SaaS; Tigris is more precisely a managed cloud object-storage service for developers. Both are delivered online, but they solve different jobs.

One company, two product jobs

The new Dropbox experience adds AI search and file actions to the familiar file-storage and collaboration workspace. DBX Agent Cloud is a separate infrastructure direction: Dropbox says it starts with standalone object storage that companies can buy independently and use alongside their chosen cloud and compute providers. The Tigris acquisition is part of that developer-facing direction, not a change to what everyday Dropbox folders are for.

What teams can do in the new Dropbox experience

Dropbox says people can ask questions about files, summarize folders, compare versions, draft documents, edit PDFs and images, transcribe recordings, and organize or rename files. Before supported changes are made, Dropbox presents a plan for approval; actions use existing permissions and can be reviewed or undone.

Availability matters: as of Dropbox’s November 17 update, the initial rollout targets eligible Standard and Advanced teams in the United States, United Kingdom, and Australia, starting in English. Dropbox says more than 70,000 teams have received the rollout and broader availability is planned for 2027. Its admin guide says the AI experience is included with Standard and Advanced, while chat requests and AI actions use team AI credits. Check the team’s access and remaining credits before planning a shared workflow.

Where Tigris fits for developers

Tigris describes its product as S3-compatible object storage for applications that run across cloud and compute providers. Developers can connect with familiar AWS SDKs and tools such as the AWS CLI or boto3. Dropbox describes DBX Agent Cloud as beginning with independently purchasable object storage; filesystem and content-processing capabilities are planned additions, not features to assume are already available.

That makes Tigris relevant when a team is building an application or agent that needs persistent files, datasets, or generated media. It is a managed cloud service, but its product category is infrastructure storage rather than a general-purpose work-management SaaS for creators.

Which product should a small team evaluate?

If your work already lives in Dropbox, first check whether the new experience is enabled for your team, which plan applies, and how shared AI credits are used. Try it on a low-risk folder and review the proposed actions before approving changes.

If you are building an AI application, evaluate Tigris or DBX Agent Cloud against your storage requirements: S3 API compatibility, where your compute runs, access controls, current pricing, and the features available today. Do not choose based on the announced roadmap alone. The practical distinction is simple: Dropbox’s workspace helps people work with files; Tigris provides object storage that developers can build into software.
