How do you keep brand names and prices intact in ElevenLabs narration?

Test brand names, version numbers and prices with an alias or supported phonemes.

By Evan · Updated Nov 18, 2026

Write down the displayed term, intended pronunciation and a full test sentence. ElevenLabs dictionaries can use aliases. Check phoneme support for your chosen model and language before using it.

ElevenLabs · View product details

Choose an alias or a supported phoneme rule

The ElevenAPI guide lists phoneme tags for eleven_v4, eleven_v4_turbo, eleven_flash_v2 and eleven_v3. For IPA or CMU in languages other than English, it lists eleven_v4 and eleven_v4_turbo. Use an alias with other models. Test the rule against the exact capitalization you use.

  • ElevenAPI pronunciation dictionaries

Change one rule and listen again

Try “Navo 3.2 starts at 19.90 US dollars.” Keep voice, model and language fixed, then add one rule. Ask a listener to write down the version and currency without the text. Record which rule you used, the model version and where the word occurs.
