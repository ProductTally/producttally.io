Two Cal.com booking links, one calendar conflict. Will both links catch it?

Configure conflict calendars separately from booking destinations and test both booking links.

By Evan · Updated Nov 18, 2026

Cal.com has separate settings for reading conflicts and writing new bookings. With Google Calendar connected, open Settings → Calendars and select the calendars under Check for conflicts. Then choose where bookings go under Add events to. You can also set a different destination in an event type's advanced settings. Choosing a destination alone does not verify that your other link will check it for conflicts. Use two personal links for this rehearsal. If a link overrides the account’s conflict settings, check its own calendar list too.

Check three events from both booking links

Use 30-minute test events and make both links read the same three conflict calendars for this rehearsal. A private busy event should hide its details, while its busy block still affects availability. A free event alone should not take the slot away. Verify this in the signed-out view and keep buffers or additional rules out of the test.

Compare both pages as a signed-out visitor on the same date and in the same time zone.

Privacy controls visibility of event details. Free/busy marks availability. If a slot behaves differently from what you expect, verify which account is connected and whether it can see the calendar's busy status.

Test each link and then test simultaneous bookings

Book through Client A's link, verify the destination calendar and reload Client B's page. The overlapping slot should disappear. If customers routinely race for a slot, make a separate test with two addresses you control and submit together. Check confirmed bookings as well as the availability shown on screen.
