Nifty recurring milestones: run a weekly review without rebuilding the plan

Create a weekly checkpoint and handle the tasks that should repeat with it.

By Evan · Published Nov 27, 2026 · Updated Nov 27, 2026

Use a Nifty recurring milestone for a weekly review that has a named deadline. Set up any tasks you expect to recur as well. The milestone can recur without its attached tasks, and changes made after recurrence is set may not be copied to the new occurrence.

Define this week's handoff

Set Friday as the review milestone. Add a Monday data pull, a Wednesday owner review and a Friday archive task. Give each either an owner or a named handoff. Before enabling recurrence, decide which tasks should appear every week and which are unique to this week.

  • Official documentation · help.niftypm.com

Review the first rollover

When the new milestone appears, check its date, task list and assignees against the plan. If you add a one-off question to a live occurrence, keep it there. If a change belongs in every week's process, review the recurrence configuration itself.
