CapCut: How do you make a horizontal cut without re-editing everything?

Keep the existing timing and replace only shots that need wider source footage or new subtitles.

By Evan · Updated Nov 18, 2026

Duplicate the CapCut project and set the horizontal canvas. Keep the existing timeline, then locate the original media for shots that need more width. Changing the aspect ratio does not recover the sides of an already cropped export.

CapCut · View product details

Keep the edit and inspect each shot

Save a copy of the edit, then set the canvas to 16:9. On a 1080 × 1920 source, filling 16:9 at the original width keeps 607.5 pixels of height, about 608. Note which clips can stay, which need original media and which need a different layout.

Rebuild the captions after the picture is stable

Adjust framing first. If subtitles are baked into the only remaining export, decide whether they still fit before adding a second layer. Rebuild captions from clean footage if available. Check the opening, middle and ending in a desktop player.
