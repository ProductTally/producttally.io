How to check a Quetext APA citation for a web page

Use Quetext to generate an APA reference, then verify the author, date, title, URL and source type against an original press release.

By Evan · Published Nov 25, 2026 · Updated Nov 25, 2026

Paste the page URL into Quetext’s citation generator and choose APA. Before copying the result into your references, reopen the page and verify the credited author or organization, the date attached to the work, the full title and the direct URL.

Read from the top of the page

Use an institutional announcement as practice. The National Retail Federation’s November 19, 2026 release about Thanksgiving weekend shopping gives you a dated press release to inspect. Start with the organization that issued it. The people quoted in the release and the company identified as conducting the survey play different roles. For the date, use the date printed with the release. Copy the headline from the page and keep the link that opens the release itself.

  • National Retail Federation’s press release

Check the source type before you paste

A press release, a downloadable report and a conventional web page can need different reference formats. If you only read the announcement, cite that announcement. If you read the full survey separately and draw a claim from it, cite that source for the claim. Match the format to the work you actually used. APA’s reference examples have entries by source type.

  • APA Style reference examples

The NRF example looks like this in an English-language APA reference list.

  • APA press release format

National Retail Federation. (2026, November 19). 183 million consumers expected to shop during Thanksgiving weekend [Press release].

  • National Retail Federation’s press release

If the output repeats an institution as both author and source, check the APA rule for the kind of work you’re citing. When the group author and publisher are the same, APA leaves the duplicate publisher out of the source element. Look for the work’s real date rather than a sitewide copyright year. One last read of those fields is usually more productive than changing punctuation in an entry whose author is wrong.
