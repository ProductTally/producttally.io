GA4 session source or first user source? Follow a returning newsletter reader

Use one visitor's journey to pick the right GA4 report for a newsletter campaign.

By Evan · Published Nov 28, 2026 · Updated Nov 28, 2026

For sessions brought in by a newsletter, use Traffic acquisition and a session-scoped dimension such as Session source / medium. Use User acquisition and First user source / medium to see how people first discovered your site. Both numbers can be right for the same person.

Acquisition reports · Traffic-source scope

One person, two visits

Imagine a reader first finds your template shop through organic search on Monday. They return Friday through a newsletter link tagged utm_source=maker_weekly and utm_medium=email. In this example, assuming GA4 recognizes the same user and records distinct sessions, organic search is the user's first acquisition source. The Friday session belongs to the newsletter. If you open the first-user report Friday to count newsletter visits, the existing customer's return visit is the wrong unit for that question.

  • Traffic-source scope

Build the Friday email report

Choose the campaign dates in Traffic acquisition. Use Session source / medium for the sender and channel, and Session campaign when several sends use the same sender. Start with Sessions and use the same date range and dimensions when you compare sends. Separately, read the User acquisition report to see which sources originally brought new users. Keep the two questions separate in the reporting notes.

  • Acquisition reports
  • Traffic-source scope

Give your weekly report an exact label

Write “sessions attributed to maker_weekly / email” beside the traffic figure. If the next question is which channel receives credit for a purchase, check the attribution report and model explicitly. A source attached to a session and credit assigned to a key event answer different questions.
