Every ranking page covers the same point. Should your Frase outline include it?

Use a real contrast-ratio query to separate essential answers, common outline sections and useful examples you can verify yourself.

By Evan · Updated Nov 18, 2026

Include it if it helps the reader finish the job. Someone searching for WCAG text contrast needs the minimum ratio and may already be trying to choose a gray for a billing screen. Answer the standards question, then use a real color pair to show how the rule affects that choice. Frase SEO Research compares ranking pages and flags possible gaps. Use those suggestions as questions to investigate.

Compare pages that give readers different things

  • Frase SEO Research

For the query WCAG contrast minimum ratio text 4.5 3 check grey background, start with three references: W3C explains the AA thresholds of 4.5:1 for ordinary text and 3:1 for large text, MDN explains how contrast applies in a web design, and WebAIM provides a calculator for the colors you have. These are handpicked examples. Search results and positions vary by market and date.

  • W3C text contrast criterion
  • MDN color contrast
  • WebAIM Contrast Checker

Here is a calculation for that billing screen. Using the W3C relative luminance formula, #777777 on #FFFFFF gives 4.478:1, while #666666 on white gives about 5.742:1. Rounding the first value to one decimal place makes it look like 4.5:1, but it still falls below the threshold. If the background is an image or changes with the state of a control, check the background the reader will actually see.

Turn the finding into a section readers can use

Back in Frase, specify the query and market where available. Pick the suggestions that answer the reader's next question. If another page already has a useful calculator, link to it and use your guide to explain where to find the foreground and background colors in a real design. Keep a note of how you calculated the example and when you checked it.

The reference pages above illustrate formats readers may need. If you run the query in Frase, select the intended country and language, then record the date, query and sources you reviewed. Keep the manually calculated contrast check distinct from any Frase-generated suggestion.
