Which cards should stay the same in a weekly Gamma update?

Use a Gamma workspace template for weekly changes, decisions and owners. Check the denominator and permissions.

By Evan · Updated Nov 18, 2026

Keep what a reader looks for every week: what changed, what needs a decision, and who owns the next step. Update the numbers and their definitions. Gamma lets you save a copy of an existing deck as a workspace template. The current help article lists Workspace Templates on all plans and says Enterprise admins can restrict who creates them. Check the template's sharing settings before involving the team.

Gamma · View product details

Decide what stays in the weekly template

  • Gamma Workspace Templates help

Start with one week’s finished deck. In Templates, add that deck and save the copy as a workspace template. Before sharing, check the template’s access separately. A new template starts with the workspace’s default sharing setting.

Decide what stays in the weekly template
CardKeep in the templateReplace this week
Weekly changeCurrent value, prior value and definition18/24 vs 12/20, with four tests added
Biggest riskImpact, owner and next checkpointTwo checkout tests pending, review Thursday
DecisionOptions, owner and deadlineWhether to release the test scope Friday

In this fictional project, tests passed rose from 12/20 (60%) to 18/24 (75%). Reporting six more passes alone would hide the change in scope.

Put the template to work

Create two copies and fill them with different weeks. Remove real client names or live links from placeholders. Ask a teammate with an ordinary workspace role to create a third copy. Check template and document access separately. The original announcement explains the feature's launch. Use the current help article for today's plan and permission details.
