Set up WooCommerce color variants with SEOPress ProductGroup

Map one variable product to its color variants and verify each offer against the storefront.

By Evan · Published Nov 28, 2026 · Updated Nov 28, 2026

SEOPress PRO 10.1 or later can add ProductGroup to a WooCommerce variable product after a SEOPress Product schema is configured. Prepare the purchasable variants first, then enable the group and check its output against the store.

SEOPress ProductGroup setup

SEOPress · View product details

Start with three variants customers can select

Imagine a desk mat in sand, ink and green. Keep the shared product name and description on the parent, and check each variant's SKU, image, price and stock. A green variant that is sold out should still carry its real availability wherever it is represented. The variants can share a parent identifier while keeping their individual offers.

  • Google product-variant markup

Confirm Product output before turning on ProductGroup

In SEO → PRO, enable Structured Data Types and set up an automatic Product schema for WooCommerce products or configure it for this product. Confirm that it appears on the page. In SEO → PRO → WooCommerce, enable ProductGroup output and clear the page cache. Inspect the parent productGroupID, hasVariant entries and the prices, currencies and availability under their offers. Check Google’s Rich Results Test against the public page.

  • SEOPress ProductGroup setup
  • Google product-variant markup

When the page emits more markup than you expect

Identify which plugin produces each Product graph before removing a duplicate. If an intended variant is missing, check that it exists as a real variation and that the plugin’s inclusion limit has not been reached. SEOPress documents a default maximum of 50 embedded variants. Valid markup establishes eligibility and helps describe the store’s actual catalog.
