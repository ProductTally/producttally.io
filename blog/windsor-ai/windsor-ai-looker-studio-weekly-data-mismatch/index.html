Windsor.ai and Looker Studio totals disagree? Trace one week in a table

Match a single data source, date range, and metric before diagnosing dashboard settings.

By Evan · Published Nov 26, 2026 · Updated Nov 26, 2026

When a weekly Looker Studio total differs from Windsor.ai, isolate one source, one date range, and one metric. Windsor.ai lists date settings, filters, aggregation, and field mappings among the likely causes. A small table makes it easier to see when the two sides begin to diverge.

Write down what each total includes

For Monday-to-Sunday ad spend, record the start and end dates, account, currency, and filters. Create a temporary Looker Studio table with date and the same spend field. Remove inherited filters from the diagnostic view, then restore them one at a time. If the totals disagree on only one day, check data freshness for that date.

  • Official source

Check how the total is calculated

Confirm the field represents the same measure and uses the same aggregation on both sides. Summing spend produces a different total from averaging it. Capture the filter and field names once you locate the difference so a teammate can repeat the check. If you later join sources, review join keys and row grain as a separate task.
