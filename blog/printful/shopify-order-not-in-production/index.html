Why hasn't this Shopify order gone into production in Printful?

Check payment, the variant location, fulfillment requests and Printful order status before retrying.

By Evan · Updated Nov 18, 2026

Check payment in Shopify first. Then check the fulfillment location for the affected variant and whether a fulfillment request went out. Finally, look for the order in Printful. This identifies whether the order failed to reach Printful or arrived and is waiting for another step.

Printful · View product details

The order isn't in Printful

Suppose an order for a black size M shirt is missing. Check that the order is paid and the line item is assigned to Printful even if another color already imports. On a manual store, choose Request fulfillment and confirm Send fulfillment request for that location. Search for the Shopify order number in Printful before taking any manual action there.

In Shopify, open Products, select the affected variant and check its Inventory location. If your store uses Printful’s alternative import, go to Printful Settings → Stores → Orders and check Sync as you go. This option applies to synced products and can conflict with apps that modify orders after checkout.

Check the request in Shopify’s order timeline. In progress can appear as soon as a request is sent. The timeline shows whether the fulfillment service accepted or declined it.

The order is in Printful

Read its status and any requested action. Personalization may still need artwork or approval. Address or payment warnings need their own fixes. Use Printful's status to tell whether production started, and record when the request left Shopify and when Printful showed it.
