Google crawling for ecommerce filters: which color and size URLs should stay visible?

Decide when a specific filtered assortment deserves a page and when a URL only serves navigation.

By Evan · Published Nov 27, 2026 · Updated Nov 27, 2026

Choose a crawl policy before a shop generates every combination of color, size and sort order. Google says sites that don't want filtered URLs shown in Search can prevent crawling of those patterns. If you keep selected landing pages crawlable, use consistent URL structures and accessible product links.

Official documentation · developers.google.com 1 · Official documentation · developers.google.com 2

Start with one real assortment

A shoe store can keep /shoes/ as the main category and maintain a red-running-shoes page if it has a stable selection and useful information. Size 42 combined with a temporary sort order usually belongs to the shopping interface. Leave a crawlable route to every product you want discovered through category or product links.

Check empty and repeated combinations

If you want facets crawled, Google recommends consistent filter ordering, standard parameter separators, and an HTTP 404 for combinations that genuinely have no results. When preventing crawling, test any rules against the product and category paths before deploying. Review whether already indexed URLs need a separate removal or indexing strategy.
