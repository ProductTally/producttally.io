Should a blog archive’s second page canonicalize to page one?

Give each paginated listing a crawlable URL while keeping filters and article URLs separate.

By Evan · Updated Nov 20, 2026

For a paginated collection, Google recommends a distinct URL and a self-referencing canonical for each page. Page two contains a different slice of the archive, so its canonical should point to page two. Link to the next page with a normal HTML anchor, even if the visible interface also offers a Load more button.

Make page three reachable on its own

Imagine an archive with 54 posts and 24 per page. Keep stable addresses for the first, second and third pages, and show the final six posts on the third. Give each article its own canonical page. Open page three directly in a new browser tab and verify it contains those six links without requiring two clicks on Load more. A page number encoded only in a URL fragment is not a separate crawlable page under Google’s guidance.

Handle sorting separately

Handle sorting and tags as separate decisions. A sort control may simply reorder the same collection. A curated topic page can be a separate landing page if it serves a distinct purpose. Before release, make sure the archive’s sequential links reach the last page and work in each published language.
