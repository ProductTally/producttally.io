Choose a Udemy Excel course that teaches XLOOKUP for order reconciliation

Use a small order and price-list exercise to check whether the syllabus teaches exact matches and exceptions.

By Evan · Updated Nov 23, 2026

For a Udemy Excel course on XLOOKUP, look for exact matches, missing values and the direction Excel searches. A useful practice task is to match order SKUs against a price list, then investigate the unmatched and duplicate keys before using the amounts.

Udemy · View product details

Build the lesson around an invoice you can check

Imagine a studio sells custom prints. Its price list shows A01 at $18 and B02 at $24. The exported order contains two A01 items and one C03. Look up prices by SKU: the known line totals $36, and C03 should display a visible missing-price note. Leave that line aside for review rather than entering zero or guessing a rate.

With F2:F4 as the price-list codes and G2:G4 as the amounts, the exercise can use =XLOOKUP(A2,$F$2:$F$4,$G$2:$G$4,"Missing SKU"). Follow the formula separators and function names used by your Excel language settings. A price should come from the row with the exact SKU.

Decide what to do when the same code occurs twice

Add a second A01 with a different amount and observe why a single match cannot tell you which price is current. XLOOKUP searches from first to last by default. Flag duplicates in the price table and resolve the rate with the date or pricing owner before you send the invoice. That extra step is what turns a formula lesson into a reliable reconciliation workflow.

The Udemy syllabus linked below lists match mode and search mode. Preview a lesson if available and confirm XLOOKUP is supported in the Excel version you work in. Ask whether the practice data includes both a missing row and an ambiguous row, or bring this small exercise to the course yourself.
