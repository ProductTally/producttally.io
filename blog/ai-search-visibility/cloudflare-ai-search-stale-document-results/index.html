Cloudflare Search for Agents still shows old docs? Trace the stale result

Follow one outdated passage from the public page through Cloudflare AI Search crawling, sync jobs and retrieval.

By Evan · Published Nov 28, 2026 · Updated Nov 28, 2026

If Cloudflare Search for Agents returns an old support answer, start with the source URL in the result. Compare its current content with the returned passage, then check the most recent crawl and sync before diagnosing the retrieval cache. The feature launched in beta on November 25, 2026.

Search for Agents

Read the cited page before touching a setting

Imagine migrating the setup manual for a desktop app from version 2 to version 3. Ask your site's /.well-known/search endpoint the exact customer question. Save the time, cited URL and the sentence that names version 2. If the citation leads to an old versioned URL, decide whether that archive should still answer a version-neutral question. Use one query that explicitly asks for version 3 to help distinguish an outdated copy of the current page from retrieval of a separate archive.

  • Search for Agents

A completed sync may still show the old copy

The default Search for Agents instance uses Discover crawling and a 24-hour crawl cache age. Discover ignores sitemap lastmod when deciding whether to fetch a page again. Check the instance's crawl settings and the Jobs history. A scheduled or manual sync is an indexing job that follows those crawl rules. Save the job time alongside the deploy time so you can tell whether the index had a chance to ingest the change.

  • Sync jobs

Retest the original query after the source is indexed

Check whether the returned URL and the sentence now match the current version. If you are investigating reused results, the AI Search documentation describes HIT and MISS in the cf-aig-cache-status header and says affected cached responses clear when their indexed chunks change or are deleted. Keep the original question as your regression check. The endpoint returns retrieved passages, so judge the cited text directly.
